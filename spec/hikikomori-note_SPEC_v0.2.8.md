# ひきこもりnote v0.2.8 — マガジンのお気に入り（リリース固定）

2026-11-02。0.2.7はタグ固定済み・ストア未申請として履歴を維持する。本版はその上へマガジン登録を追加し、既存のタグ・作者・表示制御・3モード・権限を維持する。

## 対象とUI

- 通常モード（ひとみしりモード）かつ拡張ONで、`https://note.com/{userId}/m/{magazineId}` と既知の `/archive`・`/hashtag` に登録導線を出す。
- 公式ヘッダではなく、マガジン見出し付近の公式「フォロー」の操作列の左端に輪郭の開いた本SVGを追加する。有料マガジンで同じ列が「購入手続きへ」になる場合も対応する。公式ボタン・フォロー状態・購入処理は変更しない。
- 本ボタンは44px以上のタッチ領域（48px）と日本語のアクセシブル名を持つ。登録欄は初期閉、トグルで開閉し、Escapeで閉じてボタンへフォーカスを戻す。`aria-expanded`・`aria-controls`を付ける。
- 登録先は未選択から①～④とグループ名で選ぶ。登録先選択は閲覧中のグループを変更しない。同一グループ内の同一マガジンは「登録済み」として追加不可、別グループには追加可能。
- PC・狭幅で公式操作列が切り替わると、表示中の列へ同じ本ボタンを移す。登録先と開閉状態は同じマガジン・同じホスト内では保持し、別マガジン・ホスト差し替えでは初期閉へ戻す。
- 左メニュー／狭幅メニューは本SVGとタイトルで表示し、新しいタブへ開く（`noopener noreferrer`）。タグは従来の新着検索、作者は従来のプロフィールへ移動する。設定画面では本SVG・タイトル・`(userId/magazineId)`のリンクを同じタブで開く。
- 設定画面からマガジンの新規手入力登録は行わない。既存項目の削除・上下・ドラッグ・別グループ移動はタグ・作者と共通で、指定順序を保持する。
- 社会復帰・重度では登録UIとお気に入り編集を停止し、保存データは保持する。全体OFFではnote上の本ボタンと登録欄を撤去する。お気に入り登録は作者の表示管理・有料記事非表示・公式フォローや購入とは独立する。

## データとJSON

通常モードのマガジンページからヘッダの歯車で専用ホームを開く場合は、`home.html#tags`で「お気に入り」を直接表示する。archive・hashtagも共通。社会復帰・重度の既存の設定導線・お気に入り編集制限は維持する。

内部のキー・4グループ・tags配列を維持し、次の項目を追加する。

```json
{"type":"magazine","userId":"kinokoro","magazineId":"m95cee8dfaa5e","displayName":"きのころコミック"}
```

userIdは既存の作者ID検証、magazineIdは`m`で始まる半角英数字、displayNameは改行なし200文字以内の既存規則を使う。余剰プロパティ・不正値は拒否する。URLは検証済みIDから生成し、外部URLを保存しない。名前は登録時のh1から取得し、自動更新や別途取得はしない。重複キーは`magazine:{小文字userId}:{magazineId}`。同名タグ・同じ作者のお気に入りとは別項目。

内部保存形式は初めてマガジンを含む保存で`tagSchemaVersion:4`へ進める。従来の2（タグ）・3（タグと作者）は読み取り可能で、自動移行・初期化は行わない。一度4に進めた形式は通常編集では下げない。破損データは正常分の表示と編集停止を行い、一般設定の保存では元のグループを保持する。

設定移行JSONは**予約済みの形式5を維持**し、items配列のtag・user・magazineを順序通り読み書きする。形式1～4の手動読み込みも維持する。旧JSONの全置換では作者・マガジンのお気に入りが解除されることを確認する。未知の種類、不正ID、余剰項目、同グループ重複は全体を保存前に拒否する。0.2.7は予約どおりマガジン入りJSONを全体拒否するため、マガジン入りJSONの旧版への復元は不可。

## 保存境界・競合・失敗

既存のバックグラウンド保存キューを共用する。`add-current-magazine`はnoteの最上位フレームに限定し、現在タブのURL・申告URL・pendingUrl・作者ID・マガジンIDを照合する。保存直前にも同じページかを再照合する。専用ホームや他ページからの新規登録要求は拒否する。通常モード・拡張ONを保存時にも検証する。

グループを明示指定し、同時操作は最新保存値に対して直列に処理する。登録済み重複・移動先重複を拒否し、移動時は保存済み項目を保持する。保存失敗では成功表示せず、自動再送もしない。結果未確認の場合は再確認完了まで操作を停止する。JSON読込は既存トークン競合確認・一括置換・転送ルール復旧・1MB制限を維持する。

## DOM・SPA・互換性

既存のDOM通知・update・リサイズ経路だけを使う。追加の監視・API取得・キャッシュ・依存・権限は不要。

識別はURLに加え、マガジンの公式NavigationItemリンク、本文外のh1、既知の見出しコンテナ、URLの作者へ向く公式クリエイターページリンク、表示中の公式操作列を確認する。SPA切替中の古いIDのナビゲーションでは登録欄を出さない。未知構造・ボタン不在・名前不正時は登録UIを出さず、公式画面は残す。PCと狭幅の両ボタンがDOMに存在しても挿入は表示中の列だけ。

Chrome・Edge・Firefox・Firefox Androidで共通の既存WebExtension基盤、SVG、標準select/buttonを利用する。Android向けの新しいAPIやクリップボード権限は追加しない。
