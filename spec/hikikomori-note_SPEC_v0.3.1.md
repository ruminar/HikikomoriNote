# ひきこもりnote v0.3.1 テーマ・設定JSON互換対応

2026-11-06。0.3.0を基準に実装する。本版はテーマと設定JSONの受け渡し対応であり、英語化は含まない。コミット・タグ・公開・リリースは行わない。

## テーマ

保存値はtheme: system / dark / light、初期値system。不正・未設定の保存値は表示時にsystemへ縮退し、読取だけでは保存しない。専用ホームの設定画面にシステム・ダーク・ライトの選択を追加する。設定保存・再読込・storage.local通知で各専用ホームに反映。未保存の選択は既存の編集保護に従い保持するが、ページの配色は保存済み設定へ追従する。

htmlのdata-themeとCSS変数で専用ホーム全体を配色する。systemはprefers-color-schemeで端末・ブラウザの変更へ即時追従。入力・select・textarea・ボタン・お気に入り・警告・結果・テーマ付き確認dialogとフォームのcolor-schemeを含む。note公式ページのCSS・配色には適用しない。新しい権限・外部通信なし。

## 入出力と形式

書き出しはhikikomori-note-settings / schemaVersion:7を維持し、settings内にthemeを追加する。既存の共通項目名・items表現を維持し、内部更新番号・無視した項目・Ollama等を出力しない。0.3.0の厳格な読込器にはtheme付きJSONは読めないため、ひきこもりnoteへの移行先は0.3.1以降とする。

読み込みはsettingsオブジェクトを持つラッパー形式と、設定項目を直接置くオブジェクトを受け付ける。format・schemaVersionは省略・未知でも拒否しない。既知の旧形式は変換の参考とするが、項目の存在と構造を優先する。壊れたJSON・ルートやsettingsがオブジェクトでないもの・1MiB文字数上限超過は無変更で拒否する。

対応項目：enabled / dashboardDisabled / hideArticleRecommendations / hidePaidArticles / hideLikeCounts / keepNoteHeaderVisible / noteLogoBrowserBack（boolean）、noteUserId（空文字可）、mode（normal/severe/social）、theme、tagGroups、selectedTagGroupId、authorDisplayRules。legacyModeはmodeが省略されているときのみbooleanをnormal/severeへ変換する。現代のmodeが書かれていればそちらを優先し、不正modeを旧値で補完しない。

- 対応する有効な項目だけ上書きし、省略・不正項目は現在値を維持。false・空文字・空配列を省略扱いしない。
- 未知の項目・内部更新番号・Ollama接続先／モデル／プロンプトは無視し、保存・再出力しない。
- 型が違う値は別の型へ強制変換しない。表示名・グループ名・ID・タグは既存検証を用いる。
- 検証結果を適用予定と無視（項目パス・理由）で表示し、保存成功後に実際の結果として表示。JSON値そのものを結果文へ複写しない。HTMLとして解釈しない。
- 適用可能な項目がない場合は保存せず、無視理由を表示。プレビューと保存直前の再解析を共通化し、現在値は保存キュー内で取得する。競合トークン・保存失敗時のルール復元・結果未確認時の再送停止は維持する。

## お気に入りと作者ルール

固定ID group1〜group4を使い、入力配列の並びに依存せずIDで対応。書かれていないグループ／name／itemsは現在値を維持する。itemsがあれば優先し、旧形式のtagsにも対応。type:tagは内部文字列、user/magazine/membershipは既存の各形式へ変換。各項目の未知プロパティを除外した後に既存検証を使う。重複は先頭を優先し後続を無視して報告する。

有効な項目がある配列はそれらで置換し、不正項目だけを飛ばす。明示的なitems:[] / tags:[]は対象グループを空にする。tagGroups:[]は全4グループのお気に入りだけを空にし、名前は維持する。配列が非空で全項目不正の場合は既存一覧を維持し、その旨を報告する。未知・重複グループIDは無視する。

authorDisplayRulesはuserId/displayName/action(hide/allow)で対応。[]は全解除、有効なルールがある場合はそれらで置換。重複は大文字小文字を区別せず先頭優先。非空で全件不正なら現在値を維持。自分のルールも保存可能だが、既存どおり表示処理では自己を除外する。

## おしゃべりnoteとの照合

提供サンプルは形式確認用。個人名・タグ・接続先等を初期値／固定値にしない。検証用fixtureは匿名の合成値へ置き換える。

手元のOshaberiNote/src/common.js（読取のみ）を確認。現在の読み込みはhikikomori-note-settingsのschemaVersion 1〜7を受け付け、themeも取り込む。こちらの書き出しを形式7のまま保つため、現行の完全な書き出しJSONの共通項目については読み戻し可能。OshaberiNoteのOllama設定は現在値を維持する。mode・noteLogoBrowserBackは同製品の共通機能対象外として扱われる。

ただし同製品はformat/schemaVersionや配列内容の検証が厳格なため、省略・未知版・不正値混在の手書きJSONまで相互互換にするには同製品側にも部分読み込みと項目単位の検証・結果表示が必要。その修正は本作業では行わない。実際の配布版・将来版の読み込み互換性を保証しない。
