# ひきこもりnote v0.3.0（開発中）

2026-11-04。予定はスキ数非表示、重度ひきこもりモードの左側メニュー、利用者による重点テスト。本書の実装対象はスキ数非表示。左側メニューは仕様を別途決める。

## スキ数の非表示

設定画面に「スキ数を非表示にする」を追加。`hideLikeCounts`はboolean、初期値false。全3モード共通で、拡張ONかつ設定ONで有効。自分や表示許可した作者にも適用する。設定保存キュー・別タブ通知は既存経路を使う。

- 利用者がスキを押せるハートは残し、スキ数だけを非表示にする。
- スキを押せない評価表示専用ハートは、ハートとスキ数をまとめて非表示にする。
- 記事本文に埋め込まれたnoteの他記事リンクカードも対象とする。
- DOM上の役割、操作可能性、周辺構造を照合する。見た目だけでは判定しない。
- スキの送信・取り消しや記事遷移には介入しない。数字以外の本文・カード情報を保持する。
- 設定OFF・拡張OFF・停止時に元へ戻す。判定不能な要素は変更しない。

## 確認済みDOMと判定

一覧・記事画面の数字は「12スキ この記事にスキをつけたユーザーを見る」のようなaria-labelを持つ独立したbutton。`flex items-center justify-center`の2要素からなる直下グループ内に、`type=button`、booleanの`aria-pressed`、`data-id=Icon`・`role=img`・`aria-label=スキ`のSVGを持つハートボタンが1つあることを確認する。数値だけの表示と既知のaria-labelを照合して数字ボタンのみを隠す。押下状態や一時的な無効状態を「表示専用」と読み替えてハートを消さない。数字ボタンから開くスキユーザー一覧への入口も非表示になる。

表示専用の確認済み構造は公式埋め込みの`p-noteEmbed > p-noteEmbed__inner`内の`p-noteEmbed__suki`。直下に`p-noteEmbed__sukiIcon`と数値だけの`p-noteEmbed__sukiLabel`、前者に`i.c-icon.c-icon--heart`があること、同じカードに公式記事への`a.p-noteEmbed__link`と`p-noteEmbed__body`があることを確認する。表示欄とその祖先にリンク・ボタン・tabindex等がある場合、または表示欄内に操作部品が混在する場合は変更しない。記事全体を覆う遷移リンクは表示欄の兄弟要素なので保持できる。

2026-11-04に公開作者ページ`https://note.com/ruminar`、記事`https://note.com/ruminar/n/na68901f3be0b`、その本文内にある`https://note.com/embed/notes/n7cb755a96b56?theme=auto`のDOMを読み取り確認した。数字の大きさや記事・作者ID、SVGのパス形状は固定しない。上記以外の未知構造は追加資料が得られるまで保持する。

## 埋め込みと復元

noteの本文カードは`https://note.com/embed/notes/n...`のiframe。親のCSS・MutationObserverは別文書内に届かないため、既存の250ms再同期で同一オリジンの公式埋め込み文書だけを確認する。新しいフレーム通信・content script・権限・監視タイマーは追加しない。

実際の文書URLとiframeのsrcのオリジン・パスを照合し、読込途中・外部・sandbox等で参照不能な文書はスキップ。iframeの同一文書内の後挿入や数値・構造変更も再判定する。親文書は既存MutationObserverのdirtyフラグで再判定し、aria-label・aria-pressed・role等の関連属性変更も監視対象に含める。

専用属性`data-hikikomori-note-like-hidden`とCSSで隠し、本文や数値の文字列・イベント・公式属性を書き換えない。iframe内には同じ専用CSSのstyle要素を追加する。設定解除・拡張OFF・停止・iframe削除・文書差し替え・参照不能時に専用属性と追加スタイルを外す。公式側の表示状態には手を加えない。

## 保存・移行

保存キーとお気に入り・作者設定の形式は維持。既存の保存値に`hideLikeCounts`がなければfalseとして読み、読取だけでは保存しない。通常設定保存・移行の競合トークンに新設定を含める。

書き出しは形式7で`hideLikeCounts`を必須booleanとして保持。旧形式1〜6は読み込み可能で新設定はfalse。型不正・未知項目・欠落は保存前に拒否する。形式7は0.2.9以前へ読み込めない。
