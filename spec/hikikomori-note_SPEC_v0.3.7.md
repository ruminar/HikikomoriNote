# ひきこもりnote 0.3.7（開発版）

「タグ登録支援」と記事メニューの「記事タグを確認」は、ひとみしりモード（通常・2段）で利用できる。重度ひきこもりモードと社会復帰モードでは表示しない。

拡張がONでダッシュボードを非表示にしているとき、noteのアカウントメニューの「設定」の左に「＠表示名」を表示する。メニューのクリエイターページへのリンクからログイン中のユーザーを特定し、そのユーザーの記事検索を新着順で開く。ツールチップは「自分の記事を新着順で検索」とする。

タグ登録支援を開いている間に対象外モードへ切り替えた場合は、重度では案内画面、社会復帰では設定画面に戻す。一括登録ダイアログを開いている場合は閉じる。登録済みのお気に入りと入力途中の提案文は保持し、記事の「記事全文を取得」や前後の記事へのリンクには影響しない。

設定のお気に入りでは、「移動先を選択」の右に「①の項目を全削除」を表示する。番号は選択中のグループに合わせ、空のグループではボタンを無効にする。確認画面で対象の番号・名前と件数を示し、承認後にそのグループの項目だけを削除する。グループ名と他のグループは保持する。確認後の保存時にグループ内容または選択の変更を検出した場合は、最新の状態での確認を求める。
