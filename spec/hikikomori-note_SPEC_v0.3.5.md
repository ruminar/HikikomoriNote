# ひきこもりnote 0.3.5（開発版）

2026-11-17。公開済み0.3.4のタグ・提出物は変更せず、次の開発版を0.3.5とする。0.3.4は利用者がFirefoxストア版の左メニューのドラッグ動作を確認し、設定画面の版番号表記だけの問題として受け入れた。

## 今回の変更範囲

タグ発見・一括登録支援は[tag-discovery-bulk-registration.md](tag-discovery-bulk-registration.md)を参照。設定画面と記事画面に共通の選択・保存処理を追加し、おしゃべりnoteのチャット入口は別リポジトリの作業として切り分ける。

- manifestと設定画面右上・フッターの版番号を0.3.5に揃える。
- パッケージ生成時に設定画面の2か所の版番号をmanifestと照合する。不一致・欠落では既存出力を消す前に生成を拒否する。
- 配布物に全ランタイムファイルとドラッグ処理が含まれ、現在のソースと一致することを自動テストで確認する。
- 通常のdist直下のChromium／Firefox読み込み用フォルダとZIPを同じソースから生成し、内容を照合する。以前の提出物は保持する。

設定キー・保存形式・設定JSON・権限・既存機能の動作は変更しない。旧版との互換説明にある「0.3.3以降」は版番号表示ではないため維持する。

## タグ追加ボタンの配置試行

タグ画面（/tag/・/hashtag/）では、未登録タグの追加ボタンを「＃」とし、「フォロー中のTL」の左に横並びで配置する。作者追加と同じ既存の行・アイコンボタンクラスを使い、左サイドバーとハンバーガー内で共通にする。

クリックは従来どおり選択中グループへの直接追加。登録済みの場合は＃を表示しない。ツールチップ・読み上げにはタグ名と「お気に入りに追加」を含める。保存中・結果未確認・不正設定時の無効化、状態表示、再確認、通常／2段／社会復帰／重度の適用条件は既存処理を維持する。利用者の実機確認後に採否を決める。

## 単一検索語のタグ登録

/searchのqが単一語の場合も、未登録なら［＃］を表示する。前後の空白と先頭1個の#を除き、空欄・途中の空白・#・引用符・コロン・先頭の除外記号は対象外。作者指定や複数語をタグとして登録しない。検索対象contextによらず同じ条件を適用する。

登録後は既存形式のタグとして保存し、再訪先は#付きタグ検索になる（元のキーワード検索そのものの保存ではない）。UIと背景処理は共通の判定関数を使い、背景側は既存の現在タブURL照合後に検索語を取り出す。任意タグをコンテンツから受け取らない。既存のタグ画面・グループ制限・競合検証は維持する。

## 検索メンバーシップタブ

拡張有効かつhidePaidArticlesがtrueの場合、/searchの公式メンバーシップタブだけを非表示にする。実DOMで確認したa[data-id="NavigationItem"]、同一originの/searchとcontext=circle、直属LIとUL、同じ一覧の記事タブ（context=note）で対象を限定する。LIへ専用属性を付けて隠し、設定OFF・拡張OFF・停止・対象外ページでは解除する。既存DOM更新時に追従し、新規タイマーは追加しない。

context=circleのURLへの直接アクセス・検索結果・検索語・URLは変更しない。作者ページや検索結果内のメンバーシップ導線、マガジン・記事・クリエイターのタブは維持する。
