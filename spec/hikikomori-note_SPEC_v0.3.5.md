# ひきこもりnote 0.3.5（開発版）

2026-11-17。公開済み0.3.4のタグ・提出物は変更せず、次の開発版を0.3.5とする。0.3.4は利用者がFirefoxストア版の左メニューのドラッグ動作を確認し、設定画面の版番号表記だけの問題として受け入れた。

## 今回の変更範囲

- manifestと設定画面右上・フッターの版番号を0.3.5に揃える。
- パッケージ生成時に設定画面の2か所の版番号をmanifestと照合する。不一致・欠落では既存出力を消す前に生成を拒否する。
- 配布物に全ランタイムファイルとドラッグ処理が含まれ、現在のソースと一致することを自動テストで確認する。
- 通常のdist直下のChromium／Firefox読み込み用フォルダとZIPを同じソースから生成し、内容を照合する。以前の提出物は保持する。

設定キー・保存形式・設定JSON・権限・既存機能の動作は変更しない。旧版との互換説明にある「0.3.3以降」は版番号表示ではないため維持する。

## タグ追加ボタンの配置試行

タグ画面（/tag/・/hashtag/）では、未登録タグの追加ボタンを「＃」とし、「フォロー中のTL」の左に横並びで配置する。作者追加と同じ既存の行・アイコンボタンクラスを使い、左サイドバーとハンバーガー内で共通にする。

クリックは従来どおり選択中グループへの直接追加。登録済みの場合は＃を表示しない。ツールチップ・読み上げにはタグ名と「お気に入りに追加」を含める。保存中・結果未確認・不正設定時の無効化、状態表示、再確認、通常／2段／社会復帰／重度の適用条件は既存処理を維持する。利用者の実機確認後に採否を決める。

## 検証と作業範囲

構文・既存自動テスト、両ブラウザの生成物とソースの一致、manifestと画面の版番号一致を確認する。実機の表示・ドラッグ操作は利用者の確認と区別する。

今回は開発版の準備までとし、コミット・Push・タグ作成・公開・0.3.4タグの変更は行わない。

## 確認結果

2026-11-17：構文検証・自動テスト522件成功。両ブラウザの通常配布フォルダとZIPを生成し、各21ファイルの一致、ランタイムと現在ソースの一致、manifestと右上・フッターの0.3.5表記を確認。PC・Android実機での0.3.5の表示・操作は未確認。
