# 設定のお気に入り整理画面（0.3.4）

2026-11-16。おしゃべりnoteのFAVORITES_ORGANIZER_SPEC_0.1.3.mdと現行home.js/home.html/home.cssを参照し、設定のお気に入り整理画面を移植する。相手側は変更せず、ひきこもりnoteの通常／2段・社会復帰・重度の表示条件、4／8グループ、既存5種の項目、保存キュー・競合検証・JSON形式を維持する。コミット・Push・公開は行わない。

- タグ手入力の追加フォームを外す。登録は既存のnote上のタグ・作者・マガジン・メンバーシップ・記事の追加UIを使用する。AIからの登録はひきこもりnoteには存在しないため案内しない。
- グループ名変更欄の下に共通の「移動先」を1つ置き、初回未選択とする。自分のグループと非表示グループは除外し、無効になった選択は未選択へ戻す。選択は画面内メモリだけに保持し、設定・JSONへ追加しない。
- 各行はリンクと↑・↓・削除・移動。移動は塗りボタンで削除から少し離す。PCは操作列を揃え、狭幅ではリンクと操作列を上下配置する。
- 一覧だけをスクロールし、移動先はその外へ置く。グループごとの位置を再描画・外部同期・削除・並べ替え・移動でも保持する。末尾が縮めばブラウザにより最大位置へ補正する。追加タイマー・監視・stickyは使わない。
- 未選択・保存中・結果不明・破損時は移動を無効化。成功と保存中は一覧近くのrole=statusだけに表示する。エラーと再確認は既存の全体案内も維持する。
- 操作成功後は同じ項目または隣の項目の対応ボタンへフォーカスを戻し、スクロールを強制しない。空なら一覧へ戻す。ドラッグ並べ替えも維持する。
- インポート成功時は画面内の移動先・位置・ドラフトをリセットする。登録済みデータを画面変更だけで消さない。

既存の手入力欄に依存する試験を、整理画面の宛先・連続操作・失敗／競合・位置／フォーカス・ドラッグ・モード変更・インポート・全5種の確認へ更新する。実機のPC／スマートフォン表示は自動DOM試験と区別して報告する。
