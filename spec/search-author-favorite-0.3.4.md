# 作者検索画面から選択中グループへ追加

確定仕様。既存のfrom:@ユーザーID検索の識別・作者カード・4／8グループ・作者お気に入り形式を再利用する。試作のShift操作は含めない。バージョン・JSON形式は変更しない。

- 通常／2段のひとみしりモードで、識別できる作者検索画面の「フォロー中のTL」の直前に＠ボタンを配置する。同じ行に並べ、既存のプロフィール用アクション行のレイアウトを再利用する。狭幅のハンバーガーメニューも同じ動作。
- 選択中のグループに作者が未登録の場合のみ表示する。他グループへの登録は表示条件にしない。同じグループの重複はユーザーIDの大文字小文字を区別せず防止する。
- titleとaria-labelで「作者名をグループ①に追加」のように作者・登録先を明示する。押下で選択中のグループへ直接追加し、遷移や追加ダイアログは発生させない。
- 作者IDは検索URLから、表示名は既存の作者カードと同じ情報から取得する。名前が取れない場合は空のdisplayNameで保存し、既存のID表示へ縮退する。検索結果がない場合に画像を補完しない。
- 保存中は連打・グループ操作を抑止。保存成功後は＠ボタンを消し、結果をstatusへ表示する。別の未登録グループへ切り替えると再表示する。保存失敗はボタンを残して通知、保存結果不明は自動再送せず既存の「状態を再確認」を使用する。
- 背景処理はnoteメインフレームの現在の検索URL・検索作者ID・選択グループIDと選択リビジョンを検証する。保存直前にもページ・作者が変わっていないことを確認する。既存の作者追加操作と単一書込キューを再利用し、プロフィールからの追加権限は広げない。
- 設定変更・グループ切替・SPA遷移・作者情報の後挿入で既存の再描画に追従する。社会復帰・重度・拡張OFF・作者を識別できない検索は追加ボタン対象外。新規タイマー／監視／権限／設定キーは追加しない。

自動確認：表示・追加・成功後非表示・別グループへの追加・大文字小文字・4／8・狭幅・失敗／結果不明・重複・選択変更／URL変更の競合・メッセージ送信元・既存JSONとの互換を確認する。利用者のPC／スマートフォン上の最終確認と自動DOM試験は区別して報告する。コミット・Push・公開は行わない。
