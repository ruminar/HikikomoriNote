# ひきこもりnote 0.3.6（開発版）

公開記事・作者・マガジン・メンバーシップのお気に入り登録欄では、登録先を選び、従来の追加ボタンを使う。通常クリックで末尾、CtrlまたはShiftを押しながらのクリックで先頭に追加する。保存中・結果未確認・登録済みのときは追加を無効にする。

タグページと単一語の検索結果にある「＃」、作者検索結果にある「＠」は、選択中のグループへその場で登録する。通常クリックは末尾、CtrlまたはShiftを押しながらのクリックは先頭へ追加する。左メニューとハンバーガーで同じ操作を使う。

記事ページの「記事タグを確認」と専用ホームの「タグ登録支援」は、共通ダイアログの「選択したn件を登録」で保存する。通常クリックで末尾、CtrlまたはShiftを押しながらのクリックで先頭に追加する。追加するタグは候補一覧の順序を保ったまままとめて挿入し、登録済みのタグは元の位置に残す。未選択・保存中・結果未確認では追加を無効にする。

追加位置を保存要求で渡し、既存の保存キューで対象グループの先頭または末尾へ挿入する。位置の省略は末尾として扱い、不正な値で保存しない。保存形式、設定JSON、重複制限、表示中のページの照合は従来どおり。

お気に入り一覧の縦スクロール位置はグループごとに保持する。同じグループでタグを開いたり一覧が再描画されたりしたときは元の位置に戻す。別グループから切り替えたときは保存位置を復元し、現在の検索に対応するハイライトが見切れる場合は一覧内だけを動かして表示する。ハンバーガーメニューは開いた時点で復元する。同じタブの文書遷移にはセッション領域を使い、グループIDと数値の位置だけを記録する。
