# ひきこもりnote 0.3.6（開発版）

公開記事・作者・マガジン・メンバーシップのお気に入り登録欄では、登録先を選んで「先頭に追加」「末尾に追加」のどちらかを押せる。保存中・結果未確認・登録済みのときは両方を無効にする。

タグページと単一語の検索結果にある「＃」、作者検索結果にある「＠」は、選択中のグループへその場で登録する。通常クリックは末尾、CtrlまたはShiftを押しながらのクリックは先頭へ追加する。左メニューとハンバーガーで同じ操作を使う。タグの一括登録は末尾に追加する。

追加位置を保存要求で渡し、既存の保存キューで対象グループの先頭または末尾へ挿入する。位置の省略は末尾として扱い、不正な値で保存しない。保存形式、設定JSON、重複制限、表示中のページの照合は従来どおり。
