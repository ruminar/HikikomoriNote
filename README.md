# ひきこもりnote 0.2.3（開発版）

0.2.3では作者ごとの表示管理を追加しました。設定画面の「ユーザーの表示管理」や作者ページで、非表示・表示許可・未設定を変更できます。表示名とユーザーIDを保存し、管理リストは表示名の日本語辞書順です。新規登録は作者ページまたは有料記事の3択から行い、管理画面は既存ユーザーの状態切り替えと解除だけを行います。作者ページから専用ホームを開くと「ユーザーの表示管理」へ直行します。ロゴのブラウザバック設定ON時は戻る動作を維持します。

「有料記事を非表示」がONのとき、有料記事を開くと未設定の作者に対して3択で確認します。登録済みの非表示作者の記事カードは無料記事も隠しますが、記事URL・作者ページへのアクセスは制限しません。表示を許可した作者は値札・鍵付きの有料記事も一覧に表示します。自分を除外するため、noteユーザー名の登録が必要です。手動管理は重度・拡張OFFでも可能で、拡張OFFではカード非表示と確認を停止します。購入済み一覧は対象外です。作者ページではユーザーIDによる非表示を外し、価格・鍵による有料記事の非表示だけを適用します（表示許可した作者は対象外）。

設定JSONは形式3に作者ID・表示名・選択を含めます。モードは将来の3モードに備えmode（normal／severe／social）で表し、legacyModeは出力しません。今回はnormal・severeだけを読み込み可能とし、未実装のsocialは未対応として停止します。内部の保存形式・モードUI・動作は変更していません。旧開発版の形式2も読み込めます。0.2.2の形式1も読み込めますが、現在の作者リストを解除する確認が出ます。形式3を0.2.2へ読み込むことはできません。

記事左側の固定作者情報では、未フォロー時のフォローボタンを隠します。記事上部のフォローリンクとアイコンのホバーカードは維持します。

[0.2.3仕様書](spec/hikikomori-note_SPEC_v0.2.3.md)・[確認手順](docs/manual-test.md)を参照してください。未リリースで、実拡張・Android実機での新機能の受け入れ確認はこれからです。

## 0.2.2 リリース記録

0.2.2は2026-10-29にリリース用として固定しました。タグは `0.2.2`（vなし）。Firefox Android対応と設定の移行を追加しました。2026-10-28に利用者から、USB経由の検証でAndroid 11のタブレット・Android 13のスマートフォンの両方で動作し、ハンバーガーメニューも利用できたとの報告があります。ブラウザの版番号や項目別の網羅確認は未記録で、ストア配布版の確認とは区別します。

プレビュー記事（`/preview/n...`）にも、通常記事と同じ固定の「フォロー中のTL」と作者ページへのボタンを追加しました。幅1100px以上かつ左余白が十分な場合に表示し、重度モード・拡張OFFでは非表示にします。アクセスキーは保存しません。構文検証・自動テスト153件が成功しています。

通常モードのフォロー中・タグ・検索・トピックで、左カラムが隠れる場合はロゴ左の☰から共通メニューを開閉できます。追加の検索入力はフォロー中のTL・タグ画面（tag/hashtag）を対象とし、公式ヘッダー検索欄がない／非表示の場合だけ展開領域に表示します。検索・トピックでは公式の検索欄を使用します。広幅では既存の左メニューへ戻ります。Firefox Androidは上記2端末で利用者による動作確認済みです。

「設定の移行」で保存済みの全設定・4グループのタグをJSONとして持ち運べます。「設定の書き出し」で表示し、「コピー」または手動選択で保存。別の端末で同じ欄へ貼り付け、検証と置き換え確認後に読み込みます。コピーできない場合も手動コピーできます。未保存入力は書き出さず、読み込みでは拡張ON/OFFを含めて全置換します。重度モード・拡張OFFでも利用可能です。

FirefoxからEdgeへの設定移行も利用者による動作確認済みです。0.2.1からの更新では保存済み設定を維持します。

## 0.2.1のリリース記録と継続機能

2026-10-26に0.2.1をリリース用として固定します。タグは `0.2.1`（vなし）。ストアへの更新申請は利用者が行います。

- お気に入りタグを①〜④の4グループに分類。専用ホームのタグ管理・noteの共通左メニューで選択を共有します。
- 「お気に入りタグ」でグループ名を保存し、タグの移動先を選んでグループ間移動できます。
- 保存領域は新形式専用です。空の4グループから開始し、以前の設定やタグは自動では引き継ぎません。破損データは初期化せず、警告して編集を停止します。
- 設定に「noteアイコンをブラウザバックに差し替える」を追加（既定OFF）。ONなら公式ロゴの通常クリックで前のページへ戻ります。同一オリジンへ戻れるときだけ戻り、外部から来た場合・履歴なし・API未対応・戻る処理の失敗時は何もせず、現在のページにとどまります（0.2.2で変更）。公式ロゴの右隣に設定用の歯車アイコンを追加し、専用ホームの初期画面を開きます。重度モードでもロゴの戻る機能は有効、全体OFFで停止。確認ダイアログは廃止しました。
- 設定の「有料記事を非表示」で、価格欄を確認できる記事カードと、タイトルの鍵アイコンを確認できるメンバーシップ限定記事を隠せます。初期値OFF。通常・重度の両モードで有効ですが、購入済み記事一覧は常に対象外。ほかの一覧では購入済み・参加済みでも価格や鍵アイコンがあれば対象です。無料・有料を問わず、記事内の「チップで応援する」枠も隠します。記事への直接アクセスは制限しません。
- note公式ヘッダーの検索欄の右隣に「×」を追加。文字があるときだけ表示し、押すと入力だけを消して検索欄へ戻ります。検索・画面移動は実行せず、重度モードでも利用可能。拡張OFFで取り除きます。
- `/topic/`配下にも「フォロー中のTL」と4グループのお気に入りタグを表示します。`/topic`・`/topic/`自体は対象外。通常モードかつ拡張ON時のみ、既存の左カラムを差し替えます。
- 左メニューから整理画面を開く入口や整理ダイアログは保留です。編集は専用ホームの左メニュー「お気に入りタグ」を使います。

構文検証と自動テスト125件は成功。利用者から表示・操作およびFirefoxでの動作確認報告があります。ブラウザ別・項目別の網羅確認とは区別します。[0.2.1設計](spec/hikikomori-note_SPEC_v0.2.1.md)と[確認手順](docs/manual-test.md)を参照してください。以下には0.2.0から継続する機能とリリース記録を残しています。

**枠を超えたら落選したので、殻を作りました。**

創作大賞に落選して傷ついた創作者が、安心してnoteを利用するためのブラウザ拡張です。

noteのホームを、自分で選んだナビゲーションとユーザー設定の画面にする非公式ブラウザ拡張です。note株式会社とは関係ありません。

## 0.1.1は「ひきこもりnote」、0.2.0は「ひとみしりnote」

0.1.1は、殻にこもって自分の創作に向き合うための「ひきこもりnote」。ホームのタイムラインから距離を置き、記事の公開・管理に必要な場所としてnoteを使います。

0.2.0は、少し外へ出るための「ひとみしりnote」。お気に入りタグやフォロー中のTLを入口に、見たい話題や人を自分で選びます。おすすめとの距離も、設定で選べます。

**外には出る。行き先は自分で決める。**

まだ殻の中にいたいときは、0.2.0でも「重度ひきこもりモード」へ切り替えられます。外へ出るか、いつ戻るかも、利用者自身が決めます。

表示名は次のように区別します。

| 状態 | 表示名 |
|---|---|
| 0.2.0以降の標準動作 | 通常モード（ひとみしりモード） |
| 0.1.1相当のシンプルな動作 | 重度ひきこもりモード |
| 拡張OFF | 通常のnote |

## 利用例：創作大賞のあと、少し距離を置きたいとき

創作大賞に本気の作品を応募したものの、理由がわからないまま落選した。運営から個別の選考理由が説明されないことは理解していても、そのあとでnoteのタイムラインを眺めるのは、精神的につらい。

そんなとき、しばらくnoteの運営やタイムラインと距離を置き、心の傷が落ち着くまで、自分の創作に向き合うために使います。noteを離れるのではなく、記事の公開・管理に必要な場所として使いながら、ホームのおすすめやタイムラインを見ずに過ごすための小さな「殻」です。

他のユーザーのページや記事の表示は妨げません。通知アイコンやブラウザのブックマークなどから、これまでどおり閲覧できます。
0.2.0では、お気に入りタグの検索やフォロー中のTLへの入口を用意しています。独自のタイムラインや、他のユーザーを登録するブックマーク機能は含みません。

通常のホームを見たくなったら、いつでも「通常のnoteを表示（拡張OFF）」で戻れます。
何を見るか、いつ戻るかは、利用者自身が決めます。

## 現在の機能

- 記事画面では、幅1100px以上かつ左に十分な余白がある場合、「フォロー中のTL」と、その下に作者のアイコン・名前を固定表示します。作者を押すとクリエーターページへ移動できます。スクロールしても同じ位置に残り、狭い画面・重度モード・拡張OFFでは非表示になります。
- タグ画面の左メニューから、表示中のタグを「タグをお気に入りに追加」で登録できます。末尾へ保存し、登録済みなら追加ボタンを表示しません。通常モードかつ拡張ON時に利用できます。
- 設定の「記事の『あなたへのおすすめ』を非表示にする」をチェックして保存すると、記事下のおすすめ欄を隠します。初期値は未選択。通常・重度の両モードで使え、解除や拡張OFFで元へ戻ります。記事本文・コメントは維持します。
- 通常モードのタグ画面にある「関連商品」枠を余白ごと非表示にします。記事一覧・関連キーワードは維持し、拡張OFF・重度モードでは元へ戻します。

- 専用ホームは左メニューの「お気に入りタグ」「設定」「設定の移行」で右側を切り替える2カラムUIです。区切り線の下に「前の画面に戻る」「<ユーザー名>のページ」「フォロー中のTL」を表示します。「前の画面に戻る」はオリジンを制限しない通常のブラウザバックで、重度モード・拡張OFFでも利用できます。履歴がなければ移動しません。自分のページは重度モードでも表示し、未選択のメニューボタンにも枠を付けます。メイン画面・上部タブは置きません。
- お気に入りタグの追加・削除・上下ボタン／ドラッグによる並べ替え。操作ごとに自動保存し、件数の固定上限はありません（ブラウザの保存容量には従います）。
- お気に入りタグを押すと、`#タグ名`のnote記事検索を新着順で開きます。専用ホームと左メニューで共通です。
- 検索でクリエイター・マガジン・メンバーシップから「記事」タブへ戻る際も、通常モードでは新着順で開きます。その後の人気・急上昇への切り替えは自由です。
- フォロー中・タグ・検索画面で確認済み構造の左サイドバーを独自ナビゲーションへ変更。プロフィール左カラムの先頭に「フォロー中のTL」を追加します。対象DOMがない場合や狭い画面では公式表示を維持します。
- 「重度ひきこもりモード」は左メニューの「設定」と自分のページへの入口を残し、右側上部にはキャッチコピーを常時表示します。初期表示はこのメッセージだけです。「設定」を押せば設定フォームが開きます。独自サイドバー・帰還ボタン・タグUIを停止し、タグと順序は保持します。拡張全体のOFFとは独立した設定です。
- 既存の通常ホーム転送、ダッシュボード無効化、ユーザー名保存、拡張アイコンからのON復帰は維持します。

記事はnote公式画面で取得・表示します。独自の記事収集・キャッシュ・AI・スキ等の自動操作はありません。タグ追加・並べ替え自体では外部通信しません。プロフィール・タグ・フォロー中のリンクを開くと通常のnoteへの通信が発生します。

## ローカル導入・更新

Edge/Chromeは、manifest.jsonのあるリポジトリ直下を開発者モードで読み込めます。更新時は拡張管理画面で再読み込みし、専用ホームと既存のnoteタブも再読み込みしてください。0.2.1からの更新は同じ保存領域を使用し、設定・タグを維持します。0.1.x・0.2.0の保存領域からの自動移行はありません。

1. Edgeはedge://extensions/、Chromeはchrome://extensions/を開き、開発者モードでこのフォルダを読み込みます。
2. 拡張アイコンから専用ホームを開き、状態の確認が成功することを確認します。
3. 「設定」でnoteユーザー名または公開プロフィールURLを入力し「ユーザー設定を保存」を押します。ダッシュボード無効化と重度モードもこのボタンで保存します。
4. 通常モードでは「お気に入りタグ」でタグを追加します。note上の独自サイドバーからタグを開けます。
5. 全体をOFFにする場合は設定下部の「通常のnoteを表示（拡張OFF）」を使います。ルール解除と保存が成功してから通常ホームを開きます。再開は拡張アイコンから行います。

Firefox（デスクトップ140以降）はFirefox用フォルダのmanifest.jsonをabout:debugging#/runtime/this-firefoxで一時読み込みします。直下のChromium用Manifestは使用しません。一時アドオンは終了時に外れます。恒久利用にはMozillaの署名済み版が必要です。

詳しくは [Edge/Chrome導入](docs/install-chromium.md)・[Firefox試用](docs/install-firefox.md) を参照してください。ZIPをクリックするだけではインストールされません。

## 開発・パッケージ生成

実行環境にReact・TypeScript・npmは不要です。開発者用の検証と生成にはNode.js 22以降とPowerShellを使います。

```powershell
./scripts/check.ps1
./scripts/package.ps1
```

`dist/HikikomoriNote-0.2.3-chromium/` と `dist/HikikomoriNote-0.2.3-firefox/`、各フォルダ名のZIPを生成します。必要な実行ファイルだけを含み、Firefox ZIPは未署名です。以前の提出物は `dist/submissions/` に固定してあり、この生成では変更しません。

## 設定・失敗時の扱い

設定は `storage.local` に保存し、背景処理の単一キューで更新します。タグは配列全体を送らず追加・削除・移動を最新状態へ適用します。移動先が削除済みなら競合を通知し、正常な保存済み状態を維持します。編集中の入力は別タブ更新で消しません。

保存結果が確認できない場合は変更操作を停止します。「状態を再確認」で最新状態を取得してください。操作を自動再送しません。不正なタグ保存値がある場合は正常項目を表示して警告し、編集を停止します。他の設定保存でも元のタグデータを消しません。問題がある場合は元データを保存して開発者へ修復をご相談ください。

## 権限・プライバシー

既存の `storage`、`declarativeNetRequestWithHostAccess`、`https://note.com/*` を使用し、追加権限はありません。Cookie・認証情報・記事本文・閲覧履歴・操作ログを収集しません。設定の外部送信・ブラウザ間同期はありません。[プライバシーポリシー](PRIVACY.md)を参照してください。

通常ホームURLと、無効化を選んだダッシュボードURLの文書移動を通信前に専用ホームへ転送し、そのURLの文書以外のリクエストも遮断します。他のURLのAPIやnote全体の通信を止めるものではありません。導入・ルール適用前に始まった通信も対象外です。
