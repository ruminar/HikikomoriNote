# ひきこもりnote 0.2.0（開発版）

**枠を超えたら落選したので、殻を作りました。**

創作大賞に落選して傷ついた創作者が、安心してnoteを利用するためのブラウザ拡張です。

noteのホームを、自分で選んだナビゲーションとユーザー設定の画面にする非公式ブラウザ拡張です。note株式会社とは関係ありません。

## 利用例：創作大賞のあと、少し距離を置きたいとき

創作大賞に本気の作品を応募したものの、理由がわからないまま落選した。運営から個別の選考理由が説明されないことは理解していても、そのあとでnoteのタイムラインを眺めるのは、精神的につらい。

そんなとき、しばらくnoteの運営やタイムラインと距離を置き、心の傷が落ち着くまで、自分の創作に向き合うために使います。noteを離れるのではなく、記事の公開・管理に必要な場所として使いながら、ホームのおすすめやタイムラインを見ずに過ごすための小さな「殻」です。

他のユーザーのページや記事の表示は妨げません。通知アイコンやブラウザのブックマークなどから、これまでどおり閲覧できます。
今後、表示する情報を絞ったタイムラインや、他のユーザーへのブックマーク機能をホーム画面に追加する可能性があります。これらは現在のバージョンには含まれません。

通常のホームを見たくなったら、いつでも「通常のnoteを表示（拡張OFF）」で戻れます。
何を見るか、いつ戻るかは、利用者自身が決めます。

## 0.2.0の機能

- 専用ホームを「メイン」「お気に入りタグ」「設定」の3タブに変更。通常モードではメインタブ内に「<ユーザー名>のページ」と「フォロー中のTL」を横並びに表示します。
- お気に入りタグの追加・削除・上下ボタン／ドラッグによる並べ替え。操作ごとに自動保存し、件数の固定上限はありません（ブラウザの保存容量には従います）。
- フォロー中・タグ画面で確認済み構造の左サイドバーを独自ナビゲーションへ変更。プロフィール左カラムの先頭に「フォロー中のTL」を追加します。対象DOMがない場合や狭い画面では公式表示を維持します。
- 「0.1.1モード（重度引きこもりモード）」は設定タブだけにし、その先頭にキャッチコピーと「自分のページ」を表示します。独自サイドバー・帰還ボタン・タグUIを停止し、タグと順序は保持します。拡張全体のOFFとは独立した設定です。
- 既存の通常ホーム転送、ダッシュボード無効化、ユーザー名保存、拡張アイコンからのON復帰は維持します。

記事はnote公式画面で取得・表示します。独自の記事収集・キャッシュ・AI・スキ等の自動操作はありません。タグ追加・並べ替え自体では外部通信しません。プロフィール・タグ・フォロー中のリンクを開くと通常のnoteへの通信が発生します。

## ローカル導入・更新

Edge/Chromeは、manifest.jsonのあるリポジトリ直下を開発者モードで読み込めます。更新時は拡張管理画面で再読み込みし、専用ホームと既存のnoteタブも再読み込みしてください。旧設定のユーザー名・ON/OFF・ダッシュボード設定は保持します。

1. Edgeはedge://extensions/、Chromeはchrome://extensions/を開き、開発者モードでこのフォルダを読み込みます。
2. 拡張アイコンから専用ホームを開き、状態の確認が成功することを確認します。
3. 「設定」でnoteユーザー名または公開プロフィールURLを入力し「ユーザー設定を保存」を押します。ダッシュボード無効化と重度モードもこのボタンで保存します。
4. 通常モードでは「お気に入りタグ」でタグを追加します。メインや独自サイドバーからタグを開けます。
5. 全体をOFFにする場合は設定下部の「通常のnoteを表示（拡張OFF）」を使います。ルール解除と保存が成功してから通常ホームを開きます。再開は拡張アイコンから行います。

Firefox（デスクトップ140以降）はFirefox用フォルダのmanifest.jsonをabout:debugging#/runtime/this-firefoxで一時読み込みします。直下のChromium用Manifestは使用しません。一時アドオンは終了時に外れます。恒久利用にはMozillaの署名済み版が必要です。

詳しくは [Edge/Chrome導入](docs/install-chromium.md)・[Firefox試用](docs/install-firefox.md) を参照してください。ZIPをクリックするだけではインストールされません。

## 開発・パッケージ生成

実行環境にReact・TypeScript・npmは不要です。開発者用の検証と生成にはNode.js 22以降とPowerShellを使います。

```powershell
./scripts/check.ps1
./scripts/package.ps1
```

`dist/HikikomoriNote-0.2.0-chromium/` と `dist/HikikomoriNote-0.2.0-firefox/`、各フォルダ名のZIPを生成します。必要な実行ファイルだけを含み、Firefox ZIPは未署名です。以前の提出物は `dist/submissions/` に固定してあり、この生成では変更しません。

## 設定・失敗時の扱い

設定は `storage.local` に保存し、背景処理の単一キューで更新します。タグは配列全体を送らず追加・削除・移動を最新状態へ適用します。移動先が削除済みなら競合を通知し、正常な保存済み状態を維持します。編集中の入力は別タブ更新で消しません。

保存結果が確認できない場合は変更操作を停止します。「状態を再確認」で最新状態を取得してください。操作を自動再送しません。不正なタグ保存値がある場合は正常項目を表示して警告し、編集を停止します。他の設定保存でも元のタグデータを消しません。問題がある場合は元データを保存して開発者へ修復をご相談ください。

## 権限・プライバシー

既存の `storage`、`declarativeNetRequestWithHostAccess`、`https://note.com/*` を使用し、追加権限はありません。Cookie・認証情報・記事本文・閲覧履歴・操作ログを収集しません。設定の外部送信・ブラウザ間同期はありません。[プライバシーポリシー](PRIVACY.md)を参照してください。

通常ホームURLと、無効化を選んだダッシュボードURLの文書移動を通信前に専用ホームへ転送し、そのURLの文書以外のリクエストも遮断します。他のURLのAPIやnote全体の通信を止めるものではありません。導入・ルール適用前に始まった通信も対象外です。

## 検証状況と未確認事項

自動テスト57件・構文検証が成功しています（従来36件と0.2.0の21件）。テストには代替DOM・APIを使っており、実ブラウザでの拡張全体の検証とは区別します。

実サイトでは未ログインのタグ画面と2人のプロフィールでDOMを確認しました。フォロー中はログインが必要で確認できず、同じ確認済み構造がある場合だけ適用する実装です。ブラウザ拡張としてのホーム描画・SPA・ログイン済みフォロー中・Firefoxの実機受け入れは未実施です。[DOM確認記録](docs/note-dom.md)と[手動確認表](docs/manual-test.md)を参照してください。
