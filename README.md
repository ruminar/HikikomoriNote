# ひきこもりnote v0.1.0

**枠を超えたら落選したので、殻に閉じこもりました。**

創作大賞に落選して傷ついた創作者が、安心してnoteを利用するためのブラウザ拡張です。

noteのホームを、自分の記事への導線とユーザー設定だけの画面にする非公式ブラウザ拡張です。note株式会社とは関係ありません。

## ローカル導入

Visual Studio、npm、ビルド作業は不要です。このフォルダをそのまま読み込みます。

1. Edgeで `edge://extensions/`、Chromeで `chrome://extensions/` を開きます。
2. 「開発者モード」を有効にします。
3. 「展開して読み込み」または「パッケージ化されていない拡張機能を読み込む」を選びます。
4. **manifest.jsonのあるHikikomoriNoteフォルダ**を指定します。
5. <https://note.com/> を開きます。既に開いていたページは再読み込みします。
6. noteユーザー名（例：`ruminar`）または公開プロフィールURLを入力して保存します。

ソースを変更した後は、拡張機能の管理画面で拡張を再読み込みし、noteのタブも再読み込みしてください。

## v0.1.0でできること

- `https://note.com/` のみ専用ホームに切り替えます。クエリ文字列・ハッシュ付きも対象です。
- 登録したユーザーの公開プロフィールから、自分の記事を開けます。
- ユーザー名とON/OFFをブラウザ内の拡張専用ストレージに保存します。
- 「通常のnoteを表示（OFF）」で通常ホームへ戻ります。右下の「ひきこもりnoteをONにする」で再開できます。
- 記事・編集・ログイン・購入・設定など、ホーム以外では専用画面を取り除きます。

**記事一覧の自動取得は未対応です。** noteの実DOMが未確認のため、仕様F-02のフォールバックとして公開プロフィールへのリンクを提供します。投稿・下書き管理はOFFにして公式ホームから操作してください。タグ登録・タグ収集・キャッシュ・AI・スキ操作はこの版に含めません。

## 権限とデータ

権限は `storage` と `https://note.com/*` 上のコンテンツスクリプトだけです。ホーム以外にもスクリプトを読み込むのは、再読み込みを伴わずホームへ戻るSPA遷移を検知するためです。拡張から通信を発行せず、Cookie・認証情報・記事本文を収集しません。プロフィールは利用者がリンクを押した時に通常のページとして開きます。

元のnoteのDOMは削除しません。画面の準備後にだけCSSで隠し、OFF・ホーム外への遷移・拡張のエラー時に解除します。拡張を無効化・再読み込みした後の古いタブも監視で解除しますが、ブラウザのタイマー抑制で遅れる場合はページを再読み込みしてください。

設定の読込失敗時は通常画面を維持します。OFFの保存失敗時もそのタブは通常表示に戻し、未保存を表示します。この場合、次回アクセスでは最後に保存できた設定が使われます。ユーザー設定はブラウザ間で同期しません。

## 構成・検証

- `manifest.json`：Chrome/Edge向けManifest V3。
- `src/common.js`：URL判定、ユーザー名検証、設定の正規化。
- `src/platform/browser-api.js`：ブラウザ拡張APIのアダプター。
- `src/content.js` / `src/content.css`：Shadow DOMによる画面と復帰処理。
- [仕様書](spec/hikikomori-note_SPEC.md) / [手動確認表](docs/manual-test.md)。

実行用ファイルはそのまま配置済みです。開発時の構文確認・ユニットテストにはNode.js 22以降を使用します（利用者の導入には不要）。

```powershell
./scripts/check.ps1
```

または `node --test tests/extension.test.cjs`。テストのDOMは最小限の代替実装であり、note実サイトのCSS・描画・SPA・ブラウザAPIの実動作を保証しません。Chrome/Edge実機の受け入れ確認は未実施です。

実装時に参照した公式資料：[コンテンツスクリプト](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[storage](https://developer.chrome.com/docs/extensions/reference/api/storage)。利用・公開前には[noteの最新規約](https://note.com/terms)と実際の挙動を再確認してください。ストア公開や規約適合性の確認完了を示すものではありません。
