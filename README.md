# ひきこもりnote

**枠を超えたら落選したので、殻を作りました。**

創作大賞に落選して傷ついた創作者が、安心してnoteを利用するためのブラウザ拡張です。noteの通常ホームから距離を置き、フォロー中のタイムラインやお気に入りを入口に、見たい記事や作者を自分で選べます。note株式会社とは関係のない非公式拡張です。

**外には出る。行き先は自分で決める。**

## 0.3.5の更新

- 記事に付いたタグや、貼り付けたタグ提案文から、選んだタグをお気に入りへまとめて登録できます。
- タグ画面や単一語の検索結果では「＃」で、選択中のグループへタグを追加できます。
- 左メニューとハンバーガーメニューでは、お気に入り項目だけがスクロールします。一覧が長くてもグループを切り替えられます。
- 検索結果の「関連する話題」は初期状態で非表示です。「新着」の隣の「関連」で開閉できます。
- 「有料記事を非表示」が有効なら、検索結果の有料記事の絞り込みとメンバーシップタブを隠します。一部の有料記事でアラートが出なかった問題も修正しました。
- おしゃべりnoteの設定JSONから、お気に入りの2段表示を引き継げます。

詳細は[0.3.5のリリース記録](docs/releases/0.3.5.md)と[変更履歴](CHANGELOG.md)を参照してください。

## 使い始める

1. ブラウザの拡張アイコンから専用ホームを開きます。
2. 自分のnoteページへの導線や作者の判定に使うには、「設定」でnoteユーザー名または公開プロフィールURLを入力します。
3. 「動作モード」を選び、「ユーザー設定を保存」を押します。
4. ひとみしりモードでは、note上の左メニューや、狭い画面のハンバーガーメニューから「フォロー中のTL」やお気に入りを開けます。

基本動作の確認にnoteアカウントは不要です。note上で公式ヘッダーに「ログイン」「会員登録」が表示されている場合、拡張の「フォロー中のTL」から空欄の新着検索を開けます。

通常のnoteへ戻るときは、設定の「通常のnoteを表示（拡張OFF）」を押してください。拡張アイコンから再開できます。

## 動作モード

| モード | 使い方 |
|---|---|
| ひとみしりモード（通常） | 通常ホームを専用ホームに切り替え、お気に入り4グループ（①〜④）を使います。 |
| ひとみしりモード（2段） | お気に入り8グループ（①〜⑧）を使います。左メニューでは2段、ハンバーガーメニューでは横1列です。 |
| 社会復帰モード | note公式ホームと公式の左メニューを使いながら、記事やおすすめの表示設定を使えます。 |
| 重度ひきこもりモード | 通常ホームを専用ホームに切り替え、お気に入りのナビゲーションを表示せずに使います。 |

2段から通常に戻しても⑤〜⑧の登録内容は保持されます。

## 主な機能

- **お気に入り** — タグ・作者・マガジン・メンバーシップ・記事を登録できます。作者検索の結果からは「＠」で追加できます。専用ホームの「お気に入り」や、グループがあるnote上のメニューで、ドラッグによる並べ替え・グループ間の移動・削除ができます。専用ホームではボタンでも操作できます。
- **記事のメニュー** — 作者ページ、作者の新着記事検索、前後の記事へ移動できます。「&」で記事をお気に入りに追加し、「記事タグを確認」からタグを選べます。「記事全文を取得」は、現在閲覧できる本文と記事情報をクリップボードへコピーします。
- **表示を整理** — おすすめ・有料記事・スキ数などを設定に応じて隠せます。作者ごとに一覧での「非表示」「表示を許可」を設定できます。
- **設定の持ち運び** — 専用ホームの「設定の移行」でJSONを書き出し、別のブラウザや端末へ読み込めます。対応する項目だけを取り込み、省略・不正・未知の項目は現在値を維持します。おしゃべりnoteの設定JSONからは共通項目を取り込めます。
- **専用ホームのテーマ** — システム・ダーク・ライトから選べます。

## ローカル導入・開発

- Chrome／Edgeは、Chromium用ZIPを展開し、拡張機能の管理画面の開発者モードで読み込みます。[Chrome／Edgeの導入手順](docs/install-chromium.md)
- デスクトップ版Firefoxの試用では、Firefox用ZIPを展開し、`about:debugging#/runtime/this-firefox` から `manifest.json` を一時読み込みします。恒久利用やAndroidでは対応する署名済み版を使います。[Firefoxの導入手順](docs/install-firefox.md)

検証とパッケージ生成にはNode.js 22以降とPowerShellを使います。

```powershell
./scripts/check.ps1
./scripts/package.ps1
```

`dist/` に、manifestのバージョンに応じた `HikikomoriNote-<version>-chromium` と `HikikomoriNote-<version>-firefox` のフォルダおよびZIPができます。更新後は拡張と、開いているnoteタブを再読み込みしてください。

## プライバシーとライセンス

設定とお気に入りはブラウザ内に保存します。「タグ登録支援」の提案用プロンプトは自分でコピーして使えます。拡張がAIサービスへ送信する処理はありません。[プライバシーポリシー](PRIVACY.md)
