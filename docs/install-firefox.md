# ひきこもりnote 0.2.1（開発版）— Firefox版の試用手順

0.2.1ではお気に入りタグを①〜④で切り替えます。グループ名の保存・グループ間移動は専用ホームの「お気に入りタグ」で行います。新しい保存領域で空の4グループから開始します。以前の設定やタグは自動では引き継ぎません。設定の「noteロゴをクリックしたときに確認する」を保存すると、公式ヘッダーロゴの通常クリックだけを標準OK/キャンセルで確認します。整理画面への新しい入口・整理ダイアログは保留です。新機能の実ブラウザ確認は未実施です。以下の一時導入・既存機能の手順は継続して使用できます。

対象はデスクトップ版Firefox 140以降です。このZIPは**未署名の申請・試用用パッケージ**です。Firefoxの通常版に恒久インストールするには、ストア配布版などMozillaが署名したものを使用してください。

## 一時的に読み込む

1. Firefox版ZIPをダウンロードして、任意のフォルダに解凍します。
2. Firefoxで `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」を押し、解凍したフォルダの `manifest.json` を選びます。
4. ブラウザの拡張機能メニューから「ひきこもりnote」を開きます。
5. 「設定と転送状態を確認しました。」が表示されることを確認します。サイトへのアクセス権限が必要な場合は `https://note.com` へのアクセスを許可します。
6. 設定タブでnoteユーザー名または公開プロフィールURLを保存します。
7. `https://note.com/` を開くか、プロフィールのnoteロゴを押すと専用ホームへ移動します。

Firefoxを終了すると一時アドオンは外れます。再度試すときは同じ手順で読み込んでください。恒久インストールや設定永続性を検証する方法ではありません。設定の保持をこの一時読込だけで保証しないでください。

「通常のnoteを表示（拡張OFF）」で通常ホームを開けます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。動作に問題がある場合は `about:debugging` から拡張を削除し、noteを再読み込みします。

## noteから継続利用向けに配布する場合

Firefox通常版で継続利用してもらうには、Mozillaの署名を受けたXPIが必要です。AMOのストア掲載なし（自己配布／unlisted）の署名を選べば、署名済みXPIをnoteの配布案内から提供できます。0.1.1はAMOへ差し替えて提出済みとの利用者報告があります（2026-10-22）。ここで生成する0.2.0は未署名・未提出です。ZIPの拡張子を `.xpi` に変えても署名済みにはなりません。

## この版の機能と確認状況

通常ホームの専用ホームへの転送、3タブのホーム、お気に入りタグの管理と新着順の記事検索、独自左メニュー、記事の固定TL・作者リンク、おすすめ欄の非表示、ON/OFF・任意のダッシュボード無効化を提供します。独自の記事収集・キャッシュ、AI、スキ等の自動操作はありません。note全体の通信を遮断するものではなく、プロフィールや記事、別URLのAPIへの通信は継続します。

非公式拡張です。Cookie・認証情報・記事本文を収集しません。設定はブラウザ内に保存します。

Firefox実機の動作・通信・権限の確認は未実施です。Chrome/Edgeは作者より動作確認済みとの報告がありますが、Firefox版は別途確認が必要です。

## ダッシュボードの無効化

専用ホームの「ダッシュボードを無効化する」にチェックし、「ユーザー設定を保存」を押します。ダッシュボード本体と全サブページへの移動を専用ホームへ戻し、note上のダッシュボードボタンを隠します。初期状態は未選択です。チェック解除後の保存、または全体OFFで通常どおり利用できます。利用者より追加機能の実ブラウザ確認済みとの報告がありますが、ブラウザ名は未記録のためFirefox個別の検証結果とは扱いません。

## 0.2.0の使い方

設定タブでユーザー名・ダッシュボード無効化・記事のおすすめ非表示・「0.1.1モード（重度引きこもりモード）」を保存します。タグは「お気に入りタグ」で追加・削除・並べ替えすると自動保存します。通常モードのタグ画面では左メニューから表示中のタグを追加できます。お気に入りは「#タグ名」の記事検索を新着順で開きます。重度モードでは設定タブだけになり、先頭のユーザー名のページへのリンクは使えます。タグと順序は削除しません。通常モードへ戻すにはモードのチェックを外して設定を保存します。

0.2.0は2026-10-25にリリース固定。Firefox個別の実機確認結果は未記録です。確認手順はリポジトリの `docs/manual-test.md` を参照してください。申請用Firefox ZIPは未署名です。
