# ひきこもりnote 0.3.4（開発版） — Firefox版の試用手順

0.3.4ではChromeの記事お気に入り追加フォームの文字色と、登録先の選択欄・選択肢の背景色を明示する修正を加えています。実機表示は確認待ちです。

0.3.3では記事のお気に入りと、8グループを使う「ひとみしりモード（2段）」を追加しました。従来のひとみしりモードは「ひとみしりモード（通常）」として4グループで使えます。2段版から通常版へ戻しても⑤〜⑧の内容は保持します。

設定画面の「設定の移行」でJSONを書き出し、別ブラウザ・端末へ読み込めます。8グループは形式9、4グループは記事なし形式7／記事あり形式8です。旧形式も読み込めます。8グループを別の製品へ移す場合は、移行先側にも8グループ対応が必要です。設定の移行前にJSONのバックアップを保存できます。

記事ページの「&」で登録先を選びます。専用ホームのお気に入りで削除・並べ替え・グループ移動ができます。通常版は①〜④、2段版は①〜⑧を選べます。

対象はデスクトップ版Firefox 140以降・Android版Firefox 142以降です。以下の一時読み込み手順はデスクトップ向けです。AndroidではAMOで公開・署名された対応版を使用してください。このZIPは未署名の申請・試用用パッケージです。通常版Firefoxへの恒久インストールには署名済みの配布版を使用します。

## 一時的に読み込む

1. Firefox版ZIPをダウンロードして、任意のフォルダに解凍します。
2. Firefoxで `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」を押し、解凍したフォルダの `manifest.json` を選びます。
4. ブラウザの拡張機能メニューから「ひきこもりnote」を開きます。
5. 「設定と転送状態を確認しました。」が表示されることを確認します。サイトへのアクセス権限が必要な場合は `https://note.com` へのアクセスを許可します。
6. 設定画面でnoteユーザー名または公開プロフィールURLを保存します。
7. `https://note.com/` を開くか、プロフィールのnoteロゴを押すと専用ホームへ移動します。

Firefoxを終了すると一時アドオンは外れます。再度試すときは同じ手順で読み込んでください。恒久インストールや設定永続性を検証する方法ではありません。設定の保持をこの一時読込だけで保証しないでください。

「通常のnoteを表示（拡張OFF）」で通常ホームを開けます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。動作に問題がある場合は `about:debugging` から拡張を削除し、noteを再読み込みします。


## 設定と確認

動作モードはプルダウンから「ひとみしりモード（通常）」「ひとみしりモード（2段）」「社会復帰モード」「重度ひきこもりモード」を選び、「ユーザー設定を保存」で反映します。通常／2段の「お気に入り」で登録・削除・並べ替え・グループ移動ができます。

基本動作の確認にnoteアカウントは不要です。設定した公開プロフィールを開き、note上の「フォロー中のTL」を使います。公式ヘッダで未ログインと確認できる場合は空欄の新着検索へ進みます。ログインや購入などの公式操作にはnote側の通常の制限が適用されます。

## 設定の移行

専用ホームの「設定の移行」で設定JSONを書き出し、移行先で読み込みます。対応項目だけを取り込み、省略・不正項目は現在値を維持します。読み込み結果で適用項目・無視した項目と理由を確認できます。8グループの設定に旧4グループJSONを読む場合、記述のない⑤〜⑧は維持します。
