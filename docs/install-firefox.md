# ひきこもりnote 0.2.2 — Firefox版の試用手順

0.2.2では、広いプレビュー記事にも固定TL・作者リンクを追加しています。2026-10-28に利用者から、USB経由の検証でFirefox AndroidがAndroid 11タブレット・Android 13スマートフォンの両方で動作し、ハンバーガーメニューもOKとの報告があります。ストア配布版の確認とは区別します。以下の0.2.1の基本操作は継続します。

0.2.1ではお気に入りタグを①〜④で切り替えます。グループ名の保存・グループ間移動は専用ホームの「お気に入りタグ」で行います。0.2.1からの更新では設定とタグを維持します。0.1.x・0.2.0からの自動移行はありません。設定画面の「設定の移行」でJSONを書き出し、別のブラウザ・端末へ読み込めます。設定の「noteアイコンをブラウザバックに差し替える」を保存すると、公式ヘッダーロゴの通常クリックで前のページへ戻り、公式ロゴの隣の歯車リンクから専用ホームの初期画面へ移動できます。同一オリジンへ戻れるときだけ戻り、外部から来た場合・履歴なし・API未対応・戻る処理の失敗時は何もせず、現在のページにとどまります（0.2.2で変更）。確認ダイアログは表示しません。整理画面への新しい入口・整理ダイアログは保留です。利用者から表示・操作およびFirefoxでの動作確認報告があります（2026-10-26）。項目別の網羅確認とは区別します。以下の一時導入・既存機能の手順は継続して使用できます。

対象はデスクトップ版Firefox 140以降・Android版Firefox 142以降です。ManifestにAndroid対応を宣言しています。以下の一時読み込み手順はデスクトップ向けです。AndroidではAMOで公開・署名された対応版を使用してください。このZIPは**未署名の申請・試用用パッケージ**です。Firefoxの通常版に恒久インストールするには、ストア配布版などMozillaが署名したものを使用してください。

## 一時的に読み込む

1. Firefox版ZIPをダウンロードして、任意のフォルダに解凍します。
2. Firefoxで `about:debugging#/runtime/this-firefox` を開きます。
3. 「一時的なアドオンを読み込む」を押し、解凍したフォルダの `manifest.json` を選びます。
4. ブラウザの拡張機能メニューから「ひきこもりnote」を開きます。
5. 「設定と転送状態を確認しました。」が表示されることを確認します。サイトへのアクセス権限が必要な場合は `https://note.com` へのアクセスを許可します。
6. 設定画面でnoteユーザー名または公開プロフィールURLを保存します。
7. `https://note.com/` を開くか、プロフィールのnoteロゴを押すと専用ホームへ移動します。

Firefoxを終了すると一時アドオンは外れます。再度試すときは同じ手順で読み込んでください。恒久インストールや設定永続性を検証する方法ではありません。設定の保持をこの一時読込だけで保証しないでください。

「通常のnoteを表示（拡張OFF）」で通常ホームを開けます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。動作に問題がある場合は `about:debugging` から拡張を削除し、noteを再読み込みします。

## noteから継続利用向けに配布する場合

Firefox通常版で継続利用してもらうには、Mozillaの署名を受けたXPIが必要です。AMOのストア掲載なし（自己配布／unlisted）の署名を選べば、署名済みXPIをnoteの配布案内から提供できます。0.1.1はAMOへ差し替えて提出済みとの利用者報告があります（2026-10-22）。ここで生成する0.2.2は未署名の申請用ZIPです。ZIPの拡張子を `.xpi` に変えても署名済みにはなりません。

## この版の機能と確認状況

通常ホームの専用ホームへの転送、左メニューでタグ管理と設定を切り替えるホーム、お気に入りタグの管理と新着順の記事検索、独自左メニュー、記事の固定TL・作者リンク、おすすめ欄の非表示、ON/OFF・任意のダッシュボード無効化を提供します。独自の記事収集・キャッシュ、AI、スキ等の自動操作はありません。note全体の通信を遮断するものではなく、プロフィールや記事、別URLのAPIへの通信は継続します。

非公式拡張です。Cookie・認証情報・記事本文を収集しません。設定はブラウザ内に保存します。

2026-10-26に利用者からFirefoxでも動作したとの報告があります。通信・権限・再起動等の項目別の網羅確認は未記録です。

## ダッシュボードの無効化

専用ホームの「ダッシュボードを無効化する」にチェックし、「ユーザー設定を保存」を押します。ダッシュボード本体と全サブページへの移動を専用ホームへ戻し、note上のダッシュボードボタンを隠します。初期状態は未選択です。チェック解除後の保存、または全体OFFで通常どおり利用できます。利用者より追加機能の実ブラウザ確認済みとの報告がありますが、ブラウザ名は未記録のためFirefox個別の検証結果とは扱いません。

## 0.2.2の使い方

設定画面でユーザー名・ダッシュボード無効化・記事のおすすめ非表示・「重度ひきこもりモード」を保存します。タグは「お気に入りタグ」で追加・削除・並べ替えすると自動保存します。通常モードのタグ画面では左メニューから表示中のタグを追加できます。お気に入りは「#タグ名」の記事検索を新着順で開きます。重度モードでは左メニューの「設定」と自分のページへの入口が残り、右側はキャッチコピーを初期表示します。「設定」を押すと設定フォームが開きます。設定したユーザー名のページへのリンクは重度モードでも左メニューに表示します。タグと順序は削除しません。通常モードへ戻すにはモードのチェックを外して設定を保存します。

0.2.2は2026-10-29にリリース固定。タグは `0.2.2`（vなし）。申請・検証記録はリポジトリの `docs/releases/0.2.2.md` と `docs/manual-test.md` を参照してください。ストアへの更新申請・審査・公開は別途行います。

## 設定の移行

専用ホーム左メニューの「設定の移行」で「設定の書き出し」を押すと、保存済み設定をJSON表示します。「コピー」または手動選択で保存し、別端末では同じ欄へ貼り付けて「設定の読み込み」を押します。検証と確認後に全設定・タグを置き換えます。拡張ON/OFFも含むため、読み込み前の確認文を読んでください。重度・拡張OFFでも利用でき、コピーが失敗しても手動コピーできます。
