# ひきこもりnote 0.3.4 リリース記録・申請用資料

固定日：2026-11-17。タグは `0.3.4`（vなし）。利用者が動作確認を完了し、リリースを判断。ストアへの提出は利用者が行う。READMEは変更せず、GitHub Releaseは作成しない。

## 更新説明（ストア貼り付け用）

```text
0.3.4の更新

・お気に入りの整理画面を改善。共通の移動先を選び、項目を続けて別グループへ移せます。グループごとのスクロール位置も保持します。
・設定画面と左メニューで、お気に入りをドラッグして並べ替え・グループ移動・削除できるようになりました。別のグループ番号へ落とすと移動、ドラッグ中に赤いゴミ箱になる現在の番号へ落とすと削除します。
・作者検索の結果画面から、選択中のお気に入りグループへ作者を追加できる＠ボタンを追加しました。
・タグ画面の有料記事と、記事末尾のチップ枠が非表示設定から漏れる問題を修正しました。
・ユーザーメニューのポイント・チャージ表示を有料記事非表示、プレミアムサービスとnote活用術の入口をおすすめ非表示に連動させました。
・note活用術の画面にも左メニューを適用し、Chromeで記事お気に入り追加フォームの文字が読みにくい問題を修正しました。

設定JSONの形式とブラウザ権限は変更していません。既存の上下・削除・移動ボタンも引き続き利用できます。
```

## 互換性・対象範囲

- 0.3.3と保存キー・保存形式・JSON形式を維持する。4グループは記事なし形式7・記事あり形式8、8グループは形式9。旧形式の読み込みも維持。
- 通常は①〜④、2段は①〜⑧。隠れているグループの保存内容は保持し、操作対象外とする。
- ドラッグは設定画面と、お気に入りグループがある共通メニュー（TL・タグ・各種検索・トピック・note活用術）の広幅／狭幅に対応する。記事や質問箱等の専用ナビへ、新たなグループ欄は追加しない。スマートフォンのタッチドラッグは保証せず、既存ボタン操作を維持する。
- note側からの変更は限定したmenu-favorite-dropだけで扱い、削除・移動・並べ替えの操作種別、メインフレーム、現在タブURL、ドラッグ開始元URL、選択グループとリビジョン、項目、移動先を検証する。一般の設定変更APIは公開しない。
- おしゃべりnote 0.1.3の現行コードと移植記録を確認し、今回の共通機能は移植済み。作者検索登録・新有料カード・新チップ枠・共通ドラッグ処理の主要11関数も一致する。おしゃべりnoteのファイル・タグ・提出物は今回変更しない。

## 権限・データ

0.3.3から権限・ホスト権限・依存ライブラリ・外部API取得の追加はない。記事本文・Cookie・認証情報・閲覧履歴・操作ログの収集は追加しない。処理対象は表示中DOMと既存のローカル設定。既存の前後記事情報取得・ユーザー操作による可視本文コピーは従来どおり。

Version 0.3.4 improves favorites management.
