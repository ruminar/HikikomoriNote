# ひきこもりnote 0.3.7 リリース・申請用資料

固定日 2026-11-25。タグ `0.3.7`。ストアへの提出は利用者が行います。

## 更新説明（ストア貼り付け用）

```text
0.3.7の更新

・お気に入りグループのタグやユーザーIDを、「＃」「＠」から共有用テキストとしてコピーできます。
・「タグ登録支援」で [#タグ名] と [@ユーザーID] を一緒に取り込めます。作者検索で同じIDの名前を確認できた場合、空の表示名を補完します。
・一括登録の選択件数・登録先・登録・閉じるを候補一覧の上にまとめました。
・「お気に入り」で、選択したグループの項目を確認してからまとめて削除できます。
・ダッシュボードを非表示にしたときは、noteのアカウントメニューに自分の記事を新着順で検索するリンクが出ます。
・重度ひきこもりモードと社会復帰モードでは、タグ登録支援と記事タグ確認を表示しません。
```

## Notes for certification

```text
HikikomoriNote is an unofficial browser extension for note.com. Version 0.3.7 adds separate copy buttons for tags and creator IDs in the selected favorites group. The output can be pasted into the extension's bulk registration screen. Copying uses the clipboard after a user click. When a note search result provides a name for the same creator ID, the extension can fill an empty favorites display name using the page's existing content.

Users can clear the items in the selected favorites group after confirmation. When the note dashboard is hidden, the account menu shows a shortcut to the signed-in user's newest articles. Browser permissions and the exported settings JSON format are unchanged.

A note account is optional for basic review. Enter a public note user ID such as ruminar, open its profile, and use the extension's Following link. If the official header shows Login and Sign up, the link opens the newest-article search. The account-menu shortcut requires a signed-in account.

Build and test from the supplied source using Node.js 22+ and PowerShell: ./scripts/package.ps1. No package installation or minification is required.
```
