# ひきこもりnote 0.3.3 リリース記録・申請用資料

固定日：2026-11-16。タグは `0.3.3`（vなし）。利用者のリリース判断を受けて機能範囲を固定する。ストア提出は利用者が行う。READMEは変更しない。GitHub Releaseは作成しない。

## 更新説明（ストア貼り付け用）

```text
0.3.3の更新

・お気に入りに記事を登録できるようになりました。記事ページの「&」から追加し、記事タイトルで再訪できます。削除・並べ替え・グループ移動にも対応します。
・「ひとみしりモード（2段）」を追加しました。通常版は4グループ、2段版は8グループ。左メニューは4個×2段、ハンバーガーメニューは8個×1段で表示します。
・通常版に戻しても⑤〜⑧の登録内容は保持します。後半グループを選択中に通常版へ戻すと①を選択します。
・フォロー中TLで、急上昇などへ移動する公式の横並びカテゴリナビを非表示にしました。
・通知欄の作者アイコンに、名前と@ユーザーIDのツールチップを追加しました。非表示設定の作者には「！」を表示します。
・「¥0〜」「割引あり」の条件付き無料記事も、有料記事非表示の対象にしました。

設定JSONは従来形式を引き続き読み込めます。8グループのJSONは形式9になります。他のアドオンへ8グループすべてを移すには、移行先も8グループに対応している必要があります。
```

## 設定互換性

- 保存キーはhikikomoriNote.settings.v2のまま。旧4グループの保存形式2〜6を読み込める。8グループを初めて保存する際は保存形式7へ移行する。
- 4グループのJSONは記事なし形式7・記事あり形式8を維持。8グループは形式9。tagGroupsの既存キーを維持し、group5〜group8を追加する。
- ⑤〜⑧は通常・社会復帰・重度へ切り替えても保持。旧4グループJSONに記載のない後半グループは消さない。
- modeのnormalは従来どおり、normal-doubleを追加。共通のグループ構造と製品固有モードは独立する。詳細は[8グループ仕様](../../spec/favorite-groups-eight.md)。
- おしゃべりnoteのコードは変更していない。記事入り4グループの往復は以前に確認済み。8グループの完全な往復には相手側の対応が必要。

## 権限・データ

0.3.2から権限・ホスト権限・依存ライブラリの追加はない。新機能のための外部API取得も追加していない。記事のお気に入りは記事ID・正規URL・タイトルのみを保存し、記事本文や画像は保存しない。通知のツールチップも表示中DOMと保存済み作者ルールだけで生成する。既存の前後記事情報取得と可視本文コピーは従来どおり。

## Notes for certification（2,000文字未満）

```text
HikikomoriNote is an unofficial extension for https://note.com/.

Version 0.3.3 adds article bookmarks to the existing favorites. Only the article ID, canonical public URL and title are saved locally. It does not fetch or store article bodies or images for bookmarks.

A new normal-double mode enables eight groups. The sidebar uses four columns and two rows; the hamburger menu uses one row. Normal mode still shows four groups. Returning to normal preserves groups 5-8 and resets a later-group selection to group 1. Hidden-group edits are also rejected by the background controller.

Other changes hide the official category strip on Following, add native name/@ID tooltips to notification avatars, and recognize zero-price-range cards with a discount badge as conditionally free paid articles. These use the displayed DOM and existing settings.

No new permissions, host permissions, dependencies or network requests were added. Existing previous/next public article metadata requests and user-initiated copying of currently viewable article content are unchanged. No hidden paid content is fetched.

Eight-group exports use JSON schema 9; four-group exports keep schema 7 or 8. Older settings remain readable. Full eight-group interchange requires support in the receiving product.

No note account is required for basic review. Enter ruminar as the public user ID in settings, open the profile, then use Following timeline. When the official header shows Login and Sign up, this link opens an empty newest-article search. The ID is a navigation destination, not a credential.

Build with Node.js 22+ and PowerShell: ./scripts/package.ps1. No npm install, bundling or minification is used. Automated validation passes 467 tests. The user requested release; exhaustive real-device validation was not performed by the agent.
```
