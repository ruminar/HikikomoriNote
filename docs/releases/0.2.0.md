# ひきこもりnote 0.2.0 リリース・ストア更新申請

固定日：2026-10-25。タグ：`0.2.0`（vなし）。拡張・ストア上の名称は「ひきこもりnote」を維持し、READMEではこの版の性格を「ひとみしりnote」と説明します。

## 更新説明（ストアへ転記可能）

0.2.0では、見たい話題や人を自分で選んでnoteを利用するためのナビゲーションを追加しました。

- 専用ホームを「メイン」「お気に入りタグ」「設定」の3タブに変更。
- お気に入りタグの追加・削除・並べ替えと自動保存。タグを押すと「#タグ名」の記事検索を新着順で開きます。
- フォロー中・タグ・検索画面の左メニューを、フォロー中のTLとお気に入りタグへの入口に変更。タグ画面から表示中のタグも追加できます。
- プロフィールからフォロー中のTLへ戻るボタン、広い記事画面に固定TLリンクと作者ページへのリンクを追加。
- 記事の「あなたへのおすすめ」を設定で非表示にできます。初期値は表示です。通常モードのタグ画面では関連商品枠も非表示にします。
- 「0.1.1モード（重度引きこもりモード）」で追加ナビゲーションを停止できます。お気に入りと設定は保持します。
- 通常ホーム転送・ダッシュボード無効化・全体ON/OFFは従来どおりです。

追加権限はありません。設定はブラウザ内に保存し、開発者への送信や独自の記事収集は行いません。

## 提出物と記録

mainの固定コミットからソースZIPを作成し、その展開先でパッケージ生成スクリプトを実行します。作業ディレクトリの未コミットファイルは含めません。

保存先：`dist/submissions/0.2.0-<コミット先頭12桁>/`

| ファイル | 用途 |
|---|---|
| `HikikomoriNote-0.2.0-chromium.zip` | Edge / Chromeの既存アイテムの更新に同じZIPを使用 |
| `HikikomoriNote-0.2.0-firefox.zip` | Firefoxの既存アドオンへの更新提出。未署名 |
| `HikikomoriNote-0.2.0-source.zip` | 審査用ソース。要求された場合に提出 |
| `submission.json` | コミットID・版番号・タグ・ZIPのSHA-256・検証結果 |

`dist` はGit管理対象外です。このフォルダを提出物として保管し、申請後に再生成した別のZIPへ置き換えないでください。ストア申請後はsubmission.jsonにストアごとの提出日・状態・提出版を追記できます。過去版のタグ・ZIPは変更しません。

## 申請時の確認

1. 3ストアとも既存アイテムのバージョン更新として対応するZIPをアップロードします。
2. 更新説明・紹介文・スクリーンショットを0.2.0の表示と合わせます。
3. 保存項目にお気に入りタグ・順序・モード・おすすめ非表示が増えています。プライバシーの回答をポリシーと整合させ、権限・単一目的の説明に追加ナビゲーションも含めます。
4. プライバシーポリシーURLはmainの最新版を使用できます： https://github.com/ruminar/HikikomoriNote/blob/main/PRIVACY.md
5. Firefoxの再現用ソースを求められた場合はsource.zipを提出します。ZIPはminify・bundleされておらず、Manifestのブラウザ別生成とファイルコピーを行います。展開先でNode.js 22以降とPowerShellを使い `./scripts/package.ps1` を実行すると両ブラウザ用を生成できます。npm installは不要です。

## 審査用の確認手順（英語・転記可能）

This extension replaces navigation to https://note.com/ with a local extension home. It does not collect browsing history or send settings to the developer. All executable code is packaged locally; no remote code is used.

1. Click the extension toolbar icon. In Settings, enter the public username "ruminar" and save. The public profile link should work without a note account.
2. Add "AI" under Favorite tags. Its link opens note's article search for "#AI", sorted by newest. Reordering and deletion are saved locally.
3. On a wide note search/tag page, the extension provides a left navigation menu. Tag pages allow adding the current tag. Public profiles include a Following TL link. Public articles show fixed Following TL and author profile links when the viewport is at least 1100px wide and sufficient left margin is available.
4. Enable "Hide article recommendations" and save to hide the "あなたへのおすすめ" region below public articles. Article content and comments remain available.
5. Enable "0.1.1 mode" and save: only Settings and the public profile shortcut remain on the local home; added navigation on note pages is removed. Saved tags remain intact.
6. "Show normal note (extension OFF)" disables redirection and restores the site UI. The toolbar icon enables the extension again.

The public home, search, profiles and articles can be tested without an account. Testing the actual Following timeline and the account dashboard requires a note account signed in on note.com; no account credentials are handled by the extension. No test-account credentials are included in this package. The optional dashboard restriction redirects /dashboard and its descendants to the local home.
