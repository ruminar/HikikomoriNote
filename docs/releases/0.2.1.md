# ひきこもりnote 0.2.1 リリース・ストア更新申請

固定日：2026-10-26。タグ：`0.2.1`（vなし）。mainの固定コミットを提出元とします。GitHub Releaseの作成・ストア申請は利用者の別作業です。

## 更新説明（ストアへ転記可能）

- お気に入りタグを4グループに分類し、名前の設定・グループ間移動に対応しました。
- 専用ホームを左メニュー形式に整理し、「前の画面に戻る」を追加しました。
- noteロゴを戻る操作へ変更できる設定と、専用ホームへの歯車リンクを追加しました。
- 「有料記事を非表示」を追加しました。初期値はOFFで、購入済み記事一覧は対象外です。
- ヘッダー検索欄にクリアボタンを追加し、トピック画面にも独自左メニューを表示します。
- 左メニューが一瞬公式表示になる現象、タグ追加時の接続エラー、検索対象の切り替えによるタグのハイライト消失を修正しました。

追加権限はありません。設定はブラウザ内に保存し、開発者へ送信しません。

**更新時の注意：旧版の設定・お気に入りタグの自動引き継ぎはありません。更新後にユーザー名・表示設定・タグを再設定してください。0.2.1内の更新では保存した設定を使用します。**

## 提出物

保存先：`dist/submissions/0.2.1-<コミット先頭12桁>/`。mainの固定コミットを`git archive`でソースZIPにし、その展開先で `./scripts/package.ps1` を実行します。未コミットのファイルは含めません。

| ファイル | 用途 |
|---|---|
| `HikikomoriNote-0.2.1-chromium.zip` | Chrome・Edgeの既存アイテムへの更新 |
| `HikikomoriNote-0.2.1-firefox.zip` | Firefoxの既存アドオンへの更新。未署名 |
| `HikikomoriNote-0.2.1-source.zip` | 審査用ソース。要求された場合に提出 |
| `submission.json` | 固定コミット・タグ・各ZIPのSHA-256・検証・提出状況 |

Node.js 22以降とPowerShellで再現できます。npm installは不要です。minify・bundle・外部コード取得は行わず、ブラウザ別Manifestの生成と実行ファイルのコピーを行います。ZIPの生成時刻等によるバイナリ差はあり得ます。検証は展開後の内容で行います。

以前の提出物とタグは変更しません。提出には上記固定フォルダのZIPを使い、再生成した別のZIPと混同しないでください。

以下を各提出時に入力できます。ログイン不要の公開画面で基本機能を確認できます。フォロー中やダッシュボード等のログイン専用機能にはnoteアカウントが必要です。共有テストアカウントの認証情報はこのリポジトリに含めません。ストアから認証情報を要求された場合は、利用者が審査担当者専用欄へ別途提供します。

```text
This extension redirects https://note.com/ to a local extension home. All code is packaged locally. Settings are stored locally and are not sent to the developer. No additional permissions are requested in 0.2.1.

1. Click the toolbar icon, choose Settings, enter public username "ruminar", and save. The profile link opens a public page.
2. Choose Favorite tags. Add "AI", switch between groups 1-4, rename a group, reorder tags, or move a tag to another group. Changes are saved locally. A tag opens note's newest article search for "#AI".
3. On a wide public search/tag/topic page, check the custom left navigation. A tag page can add its tag to the selected group. Switching search categories keeps the matching favorite highlighted. Public articles show Following TL and author links when enough left margin is available.

5. Enable logo browser-back in Settings. A normal logo click goes back only when the Navigation API permits same-origin back navigation; otherwise it opens the extension home. The gear next to the logo opens that home. No confirmation dialog is used.
6. Heavy mode removes added navigation while keeping settings and tags. Turning the extension OFF restores official navigation. The toolbar icon enables it again.

Public features need no credentials. Following feeds, dashboard and purchased articles require a signed-in note account. The extension has no separate account system. Old-version settings are not migrated; configure 0.2.1 afresh.
```

## 申請前の確認

1. 既存アイテムの更新として対象ブラウザのZIPをアップロードします。Firefox ZIPは署名済みXPIではありません。
2. 更新説明・紹介文・スクリーンショットを左メニュー形式と4グループの表示に合わせます。
3. 保存項目・収集に関する回答を [プライバシーポリシー](https://github.com/ruminar/HikikomoriNote/blob/main/PRIVACY.md) と整合させます。設定の外部送信や履歴収集は追加していません。
4. 自動テスト125件・構文検証を実行します。利用者からFirefoxでの動作と公式左メニューのちらつき解消の確認報告があります。全ブラウザ・全項目の網羅確認とは区別します。
5. 申請後は`submission.json`へ各ストアの提出日・状態を記録できます。現在の申請・審査状態を推測して記入しません。
