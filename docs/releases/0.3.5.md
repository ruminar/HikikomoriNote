# ひきこもりnote 0.3.5 リリース・申請用資料

固定日 2026-11-18。タグ `0.3.5`。ストアへの提出は利用者が行います。

## 更新説明（ストア貼り付け用）

```text
0.3.5の更新

・記事のタグや、貼り付けたタグ提案文から、お気に入りに入れたいタグをまとめて登録できるようにしました。
・タグ画面と単一語の検索結果に［＃］ボタンを用意し、選択中のお気に入りグループへ追加できるようにしました。
・左メニューとハンバーガーメニューでは、お気に入り項目だけがスクロールするため、一覧が長くてもグループを切り替えられます。
・検索結果の「関連する話題」は初期状態で非表示にし、「関連」ボタンで開閉できるようにしました。
・「有料記事を非表示」のとき、検索結果から有料記事の絞り込みとメンバーシップタブを隠します。
・おしゃべりnoteの設定JSONから、お気に入りの２段表示を引き継げるようにしました。
・設定画面のバージョン表示を修正しました。
```

## Notes for certification

```text
HikikomoriNote is an unofficial browser extension for note.com. Version 0.3.5 adds a bulk tag picker for tags already visible on an article and for tag suggestions pasted into settings. Users choose tags and a destination favorites group before saving. The extension can copy a prompt for use in a separate tool. It does not send the prompt to an AI service.

The # button adds eligible single-word searches and tag pages to the current favorites group. Group controls stay visible when scrolling long favorites lists. Related topics are hidden by default and can be toggled in search results. The existing hide-paid setting also hides the paid-article selector and membership search tab.

Settings import recognizes the two-row group preference from OshaberiNote. This adds no browser permissions, data collection, or external API calls. Existing exports and settings schemas are retained.

A note account is not required for basic review. Enter ruminar as the public user ID in settings and open the profile. With a logged-out note header, the Following button opens the newest-article search.

Build and test from the supplied source using Node.js 22+ and PowerShell: ./scripts/package.ps1. No package installation or minification is required.
```
