# ひきこもりnote 0.3.0 リリース記録・申請用資料

固定日：2026-11-05。タグは `0.3.0`（vなし）。noteのDOM変更で公式左メニューの差し替えが失敗する問題への対応を含む。ストア提出は利用者が行う。ストアのDescriptionは利用者が更新済みの説明文を使用する。READMEは変更しない。GitHub Releaseは作成しない。

## 更新説明

- note公式左メニューの新DOMに対応し、独自メニューへの差し替えと、表示前に公式メニューが一瞬見える問題を修正しました。
- スキ数の非表示を追加しました。操作できるハートは残して数値を隠し、表示専用のハートは数値と一緒に隠します。本文内のnoteカードにも対応し、設定OFF・拡張OFFで元の表示に戻ります。
- 重度ひきこもりモードにも、自分のクリエーターページへの左メニューを追加しました。お気に入りグループは表示しません。
- お気に入りの作者リンクから、その作者の新着記事を公式検索で開きます。先頭のfrom指定がある検索では、確認できた作者ページへの導線を追加します。
- 記事には作者ページと作者の新着検索へのリンク、質問箱・マガジン・メンバーシップにはTL・作者・自分のページへの固定リンクを追加しました。重度モードではTLを省略し、狭幅・余白不足・未知構造では表示しません。
- マガジン・質問箱のスキ数非表示漏れ、閲覧履歴の有料記事非表示漏れ、ログイン済みメンバーシップ本体のメニュー非表示を修正しました。
- 設定JSONは形式7となり、スキ数非表示設定を保持します。旧形式1〜6も読み込めます。形式7は0.2.9以前には読み込めないため、移行先も更新してください。

権限・外部通信・依存ライブラリは追加していません。既存のnote.com対象権限内で、公式埋め込みカード限定のフレーム処理を追加しています。

## Notes for certification（2,000文字未満）

```text
HikikomoriNote is an unofficial extension for https://note.com/. It changes navigation and visibility on official pages without independently fetching or hosting articles.

Version 0.3.0 supports the changed official sidebar DOM and prevents the original menu flashing before replacement. It adds an optional like-count filter: actionable hearts remain, while known display-only hearts and counts are hidden together. Unknown structures remain unchanged. Turning the option or extension off restores the display.

Official note.com/embed/notes/* frames use a dedicated document_start content script and CSS with all_frames enabled. Only known like displays are hidden while settings load. No new permissions, host permissions, external requests, or dependencies are added.

Navigation links lead to official author pages and newest-article searches. Wide layouts can show links on question boxes, magazines, and memberships; narrow or unknown layouts are left alone. Severe mode omits the following timeline and favorite groups. Existing article, like, purchase, and membership operations are preserved.

Settings stay in storage.local. Manual JSON export/import uses format 7 and accepts formats 1-6. No cookies, credentials, article text, browsing history, operation logs, or analytics are collected.

Automated validation passes 367 tests. The user rechecked the test list and confirmed Chrome JSON migration, main navigation, and the hamburger menu. Android was tested on an earlier version and was not retested for this release. Build with Node.js 22 or later and PowerShell: ./scripts/package.ps1.
```
