# ひきこもりnote 0.3.2 リリース記録・申請用資料

固定日：2026-11-09。タグは `0.3.2`（vなし）。利用者による全画面の遷移確認を受け、現在の機能範囲で固定する。ストア提出は利用者が行う。READMEは変更しない。GitHub Releaseは作成しない。

## 更新説明

- 記事の左側メニューに「◀ 前の記事」「次の記事 ▶」「記事全文を取得」を追加しました。「記事全文を取得」は、現在閲覧できる本文とタイトル・著者名・投稿日・公開URLをクリップボードへコピーします。未表示の有料部分やリンク先の本文は取得しません。
- 狭い画面では記事用ハンバーガーメニューを表示します。TL全幅、作者ページと作者検索の2列、前後記事の2列、全文取得全幅の4段配置です。画面幅を変えてもコピー中の状態と前後記事情報を維持します。
- 作者検索リンクからautofocus指定を外し、狭幅でも検索入力画面ではなく新着検索結果へ進むよう修正しました。
- 未ログインでも基本動作を確認できます。note上の追加「フォロー中のTL」は、公式ヘッダにログイン・会員登録が表示されている場合、空欄の新着検索を開きます。ログイン状態の保存、Cookie参照、ユーザーIDの自動取得は行いません。
- ヘッダの再確認はDOM変更フラグを使い、変化のない定期同期では走査しません。操作直前の確認は維持します。専用ホーム側は変更していません。

権限・ホスト権限・依存ライブラリ・設定JSON形式7は変更していません。前後記事の情報取得のため、既存note.com権限内の公式APIへ認証情報なしでGETを行います。記事本文の永続保存・AI送信・拡張間通信は追加していません。

## 審査時の動作確認

アドオンの基本動作の確認に、noteアカウントの作成やログインは不要です。

1. 拡張専用ホームのユーザー名に `ruminar` を入力します。これは公開ページへのリンク先指定であり、ログインや認証ではありません。
2. 自分のクリエーターページを開きます。
3. note上の「フォロー中のTL」を押すと、未ログイン時は空欄の新着検索へ進みます。お気に入りの登録・表示、作者検索、記事への移動を確認できます。
4. 記事ページは広幅なら固定左メニュー、狭幅ならロゴ左の「☰」から各操作を確認できます。

スキの送信・フォロー・購入など、note公式がログインを要求する操作にはnoteの通常の制限が適用されます。

```text
HikikomoriNote is an unofficial extension for https://note.com/.

Version 0.3.2 adds previous/next article links and a user-initiated Copy full article action to article navigation. Copy reads the currently viewable DOM only and writes the title, author, publication date, public URL and body to the clipboard. Links, loaded note cards and attachment URLs may be included. It does not fetch hidden paid content or linked article bodies, persist articles, send text to AI services, or read the clipboard.

To resolve previous/next public article links before scrolling, it requests https://note.com/api/v3/notes/{id}/extra_items once per current article/magazine context, with credentials omitted, redirects rejected and a timeout. Only public titles and URLs are used temporarily. Confirmed on-page navigation links take priority.

Narrow layouts use a hamburger menu for timeline, author, author search, previous/next and copy actions. Author searches omit autofocus so narrow layouts open results instead of the search-input overlay.

On official note pages, extension-created Following timeline links open an empty newest-article search when the current official header visibly shows Login and Sign up. Header DOM changes mark links for refresh; unchanged timer ticks do not repeat this check. Activation checks current DOM again. Login state is not retained or saved. The extension home is unchanged.

No note account or login is needed to check basic functionality. Enter ruminar as the user ID in extension settings, open that public profile, then use Following timeline to reach search and favorites. This ID is a public navigation destination, not a login credential.

Permissions and settings JSON schema 7 are unchanged. Automated validation passes 430 tests. The user confirmed correct navigation from all screens. Build with Node.js 22+ and PowerShell: ./scripts/package.ps1. No npm install, bundling or minification is used.
```
