# ひきこもりnote 0.2.6 リリース・ストア更新申請

固定日：2026-11-01。タグ：0.2.6（vなし）。mainの固定コミットから生成したZIPを使用する。ストア申請・GitHub Releaseは利用者側で行う。

## 更新説明（ストアへ転記可能）

- 「noteのヘッダを常に表示する」を追加しました（初期値OFF）。設定を保存すると、スクロール中もロゴ・歯車・検索などへアクセスできます。通常・社会復帰・重度モード共通で、設定解除・拡張OFFでは公式動作へ戻ります。
- 常時表示中は、記事の置き換え用作者行と作者ページの固定バーを非表示にします。左メニューの固定位置と最大高さもヘッダに合わせ、スクロール中の重なりを防ぎます。
- 設定JSONを形式4へ更新し、ヘッダ表示設定も移行できます。旧形式1～3も読み込めますが、ヘッダ常時表示はOFFになります。形式4を旧版に読み込むことはできません。
- 作者ページの価格・鍵付き固定記事の非表示漏れを修正しました。月別ページ（/archives）にも有料参加プランの非表示を適用します。表示許可した作者と直接アクセスの例外は維持します。

新しい権限・外部通信・依存ライブラリはありません。独自の記事取得や追加のスクロール監視は行いません。ストレージキーやタグ・作者の保存形式は維持します。

## 提出物と再現手順

保存先：dist/submissions/0.2.6-<コミット先頭12桁>/。

- HikikomoriNote-0.2.6-chromium.zip：Chrome／Edge用
- HikikomoriNote-0.2.6-firefox.zip：Firefox Desktop／Android用（未署名）
- HikikomoriNote-0.2.6-source.zip：同じコミットの審査用ソース
- submission.json：コミット・SHA-256・検証結果

ソースZIPを展開し、Node.js 22以上とPowerShellで ./scripts/package.ps1 を実行すると両ブラウザの配布物を生成できます。依存インストール・ビルド時ダウンロードはありません。
