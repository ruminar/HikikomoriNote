# ひきこもりnote 0.2.2 リリース・ストア更新申請

固定日：2026-10-29。タグ：`0.2.2`（vなし）。mainの固定コミットを提出元とします。ストアへの申請とGitHub Releaseの作成は別作業です。

## 更新説明（ストアへ転記可能）

- Firefox Androidに対応しました。狭い画面ではnoteロゴ左の☰からメニューを開き、フォロー中のTLやお気に入りタグへ移動できます。
- 「設定の移行」を追加しました。設定と4グループのお気に入りタグをJSONで書き出し、別のブラウザや端末へ読み込めます。コピーに失敗しても手動コピーできます。
- プレビュー記事にもフォロー中のTL・作者ページへのボタンを追加しました。
- 有料記事の非表示をメンバーシップ限定記事・最低価格表記に対応させ、同じ設定で記事内のチップ枠も隠します。購入済み記事一覧は対象外です。
- 記事下のおすすめ非表示、公式作者情報との重なり、ユーザー未設定時の導線を改善しました。
- ロゴの戻る操作でnote内の履歴へ戻れない場合は、現在のページにとどまります。歯車から専用ホームを開けます。

追加権限はありません。設定の自動送信・自動同期はありません。0.2.1からの更新では保存済み設定とタグを維持します。0.1.x・0.2.0からの自動移行はありません。

## 提出物と再現手順

保存先：`dist/submissions/0.2.2-<コミット先頭12桁>/`。

| ファイル | 用途 |
|---|---|
| `HikikomoriNote-0.2.2-chromium.zip` | Chrome・Edgeの既存アイテムへの更新 |
| `HikikomoriNote-0.2.2-firefox.zip` | Firefoxデスクトップ・Androidの既存アドオンへの更新。未署名 |
| `HikikomoriNote-0.2.2-source.zip` | 審査用ソース。要求された場合に提出 |
| `submission.json` | 固定コミット・タグ・ZIPのSHA-256・検証・提出状況 |
| `verification.log` | 固定ソースからの構文検証・自動テスト・生成記録 |

mainの固定コミットを `git archive` でソースZIPにし、展開先で `./scripts/package.ps1` を実行します。Node.js 22以降とPowerShellを使用し、npm installは不要です。minify・bundle・外部コード取得はありません。実行ファイルのコピーとブラウザ別Manifest生成のみです。時刻等によるZIPのバイナリ差は、展開後の内容比較で検証します。以前の提出物・タグは変更しません。

Firefox用Manifestには `gecko_android.strict_min_version: "140.0"` を含めています。AMOへ更新版を提出し、Android対応として掲載されることも確認してください。[Mozillaの互換性宣言の説明](https://www.extensionworkshop.com/documentation/publish/version-compatibility/)を参照。Chrome・EdgeにはChromium用ZIPを使用します。Firefox用ZIPは署名前のため、そのまま恒久インストールはできません。
