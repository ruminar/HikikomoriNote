# ひきこもりnote 0.2.4 リリース・ストア更新申請

固定日：2026-10-31。タグ：`0.2.4`（vなし）。mainの固定コミットから生成したZIPを提出する。ストア申請とGitHub Releaseの作成は利用者側で行う。

## 更新説明

- 社会復帰モードを追加。note公式ホームと左メニューを使いながら、有料記事・作者・おすすめの非表示や検索欄クリアなどを引き続き利用できます。
- 動作モードを「通常」「社会復帰」「重度ひきこもり」の選択式へ変更。重度でも記事・プレビュー横の作者ページ導線を表示します。
- 設定画面のメニュー順と開き先を整理。通常は設定、独自タグメニューのある画面からはお気に入りタグ、作者ページからはユーザーの表示管理へ移動します。
- 設定JSON形式3で社会復帰モードも保存・復元できます。追加権限・依存ライブラリ・外部送信はありません。

旧ストレージのlegacyModeは自動移行せず、modeがない場合は通常として起動します。タグ・作者設定は保持します。必要なら重度を選び直してください。形式1／2の手動インポートは維持します。

## 提出物

`dist/submissions/0.2.4-<コミット先頭12桁>/` 内の次のファイルを使います。

- `HikikomoriNote-0.2.4-chromium.zip`：Chrome／Edge
- `HikikomoriNote-0.2.4-firefox.zip`：Firefox Desktop／Android、未署名
- `HikikomoriNote-0.2.4-source.zip`：同じコミットの審査用ソース
- `submission.json`：コミット、SHA-256、検証結果

ソースを展開し、Node.js 22以上とPowerShellで `./scripts/package.ps1` を実行すると両ブラウザの配布物を生成できます。依存インストール・ビルド時ダウンロードはありません。
