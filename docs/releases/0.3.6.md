# ひきこもりnote 0.3.6 リリース・申請用資料

固定日 2026-11-23。タグ `0.3.6`。ストアへの提出は利用者が行います。

## 更新説明（ストア貼り付け用）

```text
0.3.6の更新

・お気に入りの追加ボタンは、通常クリックでグループの末尾、CtrlまたはShiftを押しながらクリックで先頭に追加します。記事、作者、マガジン、メンバーシップの追加や、「＃」「＠」からの追加で使えます。
・記事の「記事タグを確認」と設定画面の「タグ登録支援」でも、同じ操作で先頭に一括追加できます。選んだタグは候補一覧の順に追加し、登録済みのタグは元の位置に残ります。
・左メニューとハンバーガーメニューで、お気に入り一覧のスクロール位置をグループごとに覚えます。同じタブでタグを開いたあとも元の位置に戻り、グループを切り替えたときは検索中の項目が見える位置に調整します。
```

## Notes for certification

```text
HikikomoriNote is an unofficial browser extension for note.com. In 0.3.6, a normal click on an existing favorites add button appends to the group. Ctrl-click or Shift-click inserts at the beginning. This also works in the bulk tag dialog, which retains candidate order and skips already registered tags.

The sidebar and hamburger menu remember the scroll position of each favorites group. The tab's session storage holds only group IDs and numeric scroll offsets for this feature. When switching groups, the extension can scroll the favorites list to reveal the highlighted search item. Browser permissions and the settings JSON format are unchanged.

A note account is not required for basic review. Set a public note user ID such as ruminar, open that profile, and use the extension's Following link. When the official header shows Login and Sign up, this link opens the newest-article search.

Build and test from the supplied source using Node.js 22+ and PowerShell: ./scripts/package.ps1. No package installation or minification is required.
```
