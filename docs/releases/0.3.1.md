# ひきこもりnote 0.3.1 リリース記録・申請用資料

固定日：2026-11-06。タグは `0.3.1`（vなし）。今回は専用ホームのテーマと設定JSON互換対応だけで固定する。英語化・Ctrl＋noteロゴの遷移変更は含めない。ストア提出は利用者が行う。READMEは変更しない。GitHub Releaseは作成しない。

## 更新説明

- 専用ホームのテーマを「システム」「ダーク」「ライト」から選べます。初期値はシステムです。設定を保存して復元でき、複数の専用ホームにも反映します。システム選択時は端末・ブラウザの配色変更に追従します。note公式ページの配色は変更しません。
- おしゃべりnoteと、共通設定をJSONで受け渡せます。拡張間の直接通信・自動同期はありません。Ollama接続先・モデル・プロンプト等の専用設定は取り込まず、保持・再出力もしません。
- JSONは有効な対応項目だけを上書きします。省略・不正・未対応の項目は現在値を維持し、false・空文字・空配列も明示的な値として扱います。適用項目・無視した項目と理由を表示します。
- 形式名・版番号を省略した手書きJSONや未知の版番号にも対応します。旧形式のtags・legacyMode変換は維持します。壊れたJSONは設定を変更せずエラーにします。
- お気に入り4グループ、タグ・作者・マガジン・メンバーシップ、作者の表示管理にも対応します。明示された一覧は有効な内容で置き換えます。空配列は解除、非空で全項目不正なら現在の一覧を維持します。
- 設定の書き出しは形式7を維持してthemeを追加します。theme付きJSONのひきこもりnoteへの読み戻しは0.3.1以降が必要です。旧形式に含まれない設定を初期化する従来の読込動作から、省略項目の現在値を維持する動作に変わります。

権限・外部通信・依存ライブラリは追加していません。既存のモード・フィルタ・公式DOM判定は維持します。

HikikomoriNote is an unofficial extension for https://note.com/. It changes navigation and visibility on official pages without independently retrieving articles or timelines.

Version 0.3.1 adds System, Dark, and Light themes to the extension's own home and settings pages, including forms, warnings, JSON fields, and confirmation dialogs. System follows prefers-color-scheme. The theme is saved locally and shared through existing storage notifications within this extension. Official note pages are not recolored.

Manual JSON transfer now accepts compatible fields from Oshaberi Note and handwritten objects. Valid provided fields overwrite current values; omitted, unsupported, or invalid fields retain current values. Unknown format/schemaVersion metadata does not itself reject an import. Legacy tags and legacyMode conversion remains supported. Invalid JSON changes nothing. The UI reports applied and ignored fields with reasons.

The extension imports only its supported settings, four favorite groups, author rules, and theme. Ollama endpoints, models, prompts, and other unsupported fields are not retained or re-exported. There is no direct communication or automatic synchronization between extensions.

Exports retain hikikomori-note-settings schemaVersion 7 and add theme. Theme-containing exports require HikikomoriNote 0.3.1 or later when re-importing into this product. Complete exports were checked against the local Oshaberi Note parser; future or published peer versions are not guaranteed.

No permissions, host permissions, dependencies, external requests, analytics, or data collection are added. Settings remain in storage.local; JSON transfer is manual. Automated validation passes 390 tests. Headless Chrome checked 12 local theme/media/width combinations. The user confirmed dark display, JSON import, and stable standalone use after restarting Firefox. To reproduce packages, use Node.js 22 or later and PowerShell: ./scripts/package.ps1.
