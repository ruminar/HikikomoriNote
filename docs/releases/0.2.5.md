# ひきこもりnote 0.2.5 リリース・ストア更新申請

固定日：2026-10-31。タグ：0.2.5（vなし）。mainの固定コミットから生成したZIPを使用する。ストア申請・GitHub Releaseは利用者側で行う。

## 更新説明（ストアへ転記可能）

- 社会復帰モードで表示する公式ホームの表示制御を補完。有料記事非表示ONで価格・鍵付き記事とおすすめメンバーシップ行を非表示にし、おすすめ非表示ONで中央の運営バナーも隠します。
- 価格付き有料マガジンと、作者ページの課金・販売導線の表示制御を追加。Amazon商品・ストア商品枠・有料参加プランを設定に従って隠します。
- 表示許可した作者の有料記事・マガジン・作者ページ販促は残します。自分は作者ページ販促の対象外です。おすすめメンバーシップは作者別ではなく行全体を隠します。
- ストアへ直接アクセスした場合の商品は残し、フォロー中のTLと作者表示管理を追加。記事・作者ページへの直接アクセスや公式フォロー状態は変更しません。

既存設定を共用し、新しい権限・通信・ライブラリ・JSON形式変更はありません。販促フィルターで自分を除外するため、自分のnoteユーザー名を設定してください。未知のDOMは推測で隠しません。

## 提出物と再現手順

保存先：dist/submissions/0.2.5-<コミット先頭12桁>/。

- HikikomoriNote-0.2.5-chromium.zip：Chrome／Edge用
- HikikomoriNote-0.2.5-firefox.zip：Firefox Desktop／Android用（未署名）
- HikikomoriNote-0.2.5-source.zip：同じコミットの審査用ソース
- submission.json：コミット・SHA-256・検証結果

ソースZIPを展開し、Node.js 22以上とPowerShellで ./scripts/package.ps1 を実行すると両ブラウザの配布物を生成できます。依存インストール・ビルド時ダウンロードはありません。
