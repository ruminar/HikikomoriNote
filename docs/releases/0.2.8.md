# ひきこもりnote 0.2.8 リリース記録・申請用資料

固定日：2026-11-02。タグは `0.2.8`（vなし）。ストア提出は利用者が行う。0.2.7はタグのみ固定してストア未提出だったため、0.2.6からの更新説明には作者のお気に入りと作者ページの有料マガジン制御も含める。

## 更新説明

お気に入りにタグだけでなく、作者とマガジンも登録できるようになりました。

- 作者ページの「フォロー中のTL」の左にある＠から登録欄を開き、登録先のグループを選べます。
- マガジンページの「フォロー」または「購入手続きへ」の左にある本のアイコンから登録できます。公式フォロー・購入とは独立した機能です。
- 左メニューの作者・マガジンは新しいタブで開き、閲覧中の一覧を残します。設定ではタグ・作者・マガジンを同じ順番で並べ替え、削除、グループ間移動できます。
- マガジンページの歯車から「お気に入り」を直接開きます（通常モード）。
- 作者ページの共通欄と一覧でも、有料マガジンを既存の「有料記事を非表示」で隠します。表示許可・自分・直接アクセス等の例外は維持します。
- 設定の移行は形式5で3種類のお気に入りと順序を保存します。旧形式も読み込めますが、旧JSONで全置換する際は作者・マガジンの登録解除を確認します。マガジン入り形式5は0.2.7以前へ読み込めません。

作者・マガジンのお気に入りは通常モード（ひとみしりモード）で利用します。社会復帰・重度モードではデータを保持します。新しい権限・外部通信・依存ライブラリは追加しません。
