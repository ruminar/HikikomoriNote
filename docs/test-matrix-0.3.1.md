# 0.3.1 テーマ・設定JSONの確認

本版はテーマとJSON互換対応。英語化は含まない。結果記入欄は設けない。

| 項目 | 確認内容 |
|---|---|
| テーマ | 設定でシステム・ダーク・ライトを選択して保存。再読込・別ホームでも復元する。未保存の選択と保存済み配色を区別する。 |
| システム配色 | systemで端末・ブラウザの配色を変えると追従。固定dark/lightは端末変更で変わらない。 |
| 画面要素 | PC・狭幅で入力・select・JSON欄・お気に入り・作者管理・警告・確認dialog・キャンセル・Escape・キーボードフォーカスを確認。 |
| 適用範囲 | 全3モード・拡張OFFの専用ホームでもテーマが反映。note公式ページの配色は維持。 |
| 共通設定 | おしゃべりnoteのJSONを貼り、対応項目の適用予定・専用項目の無視理由を確認。個人設定を初期値にしない。 |
| 部分入力 | `{"theme":"dark"}`だけで他設定が維持。false、空ユーザー名、空の一覧も正しく適用。 |
| 一覧 | 4グループ、4種類のお気に入り、作者の非表示／許可を往復。グループIDで対応し、省略グループは維持。不正項目と重複は理由を表示。 |
| 不正・未知 | 未知format/schemaVersion、未知キー、不正型混在でも有効項目を取り込む。壊れたJSON・不正ルートは無変更。 |
| 旧データ | 形式1〜7のtags、items、legacyModeを読み込む。旧版に含まれない設定・作者ルールは現在値を維持。 |
| 解除 | items:[] / authorDisplayRules:[]は対象一覧を解除。tagGroups:[]は4グループのお気に入りを解除し名前を維持。 |
| 保存失敗・競合 | 別ホームでの設定変更後は古い確認内容の取込を拒否。保存失敗では元の設定を維持し、結果未確認なら再確認する。 |
| 結果・クリア | 保存後に適用項目・無視項目と理由を確認。クリアはJSONと結果だけを消し、保存設定とクリップボードは維持。 |
| 読み戻し | 自分の書き出しを再読込。おしゃべりnote側へは完全な形式7を書き出して渡す。Ollama専用設定を持ち出さない。 |

自動確認：390件成功。ヘッドレスChromeでは実際のhome.html・home.js・home.cssを使い、匿名の模擬保存ポートで3テーマ×端末配色2種×1280/390pxの12通りを確認。ダイアログの描画も撮影して確認した。実拡張のストレージ・複数ウインドウ・OSの実設定変更、Firefox・Edge・Android実機の0.3.1操作は未確認。利用者が確認する。

おしゃべりnoteの手元の読込器で、3テーマ・4種類のお気に入り・作者ルールの往復とOllama設定の維持を確認した。相手側のファイルは変更していない。ストア配布版・将来版までの保証ではない。
