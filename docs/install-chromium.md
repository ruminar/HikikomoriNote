# ひきこもりnote 0.2.0 — Edge / Chrome版の導入

1. Chromium版ZIPをダウンロードして、任意のフォルダに解凍します。使用中はこのフォルダを移動・削除しないでください。
2. Edgeで `edge://extensions/`、Chromeで `chrome://extensions/` を開きます。
3. 「開発者モード」をONにします。
4. 「展開して読み込み」または「パッケージ化されていない拡張機能を読み込む」を押します。
5. 解凍したフォルダのうち、`manifest.json` が入っているフォルダを選びます。
6. ブラウザの拡張機能メニューから「ひきこもりnote」を押して専用ホームを開きます。
7. 「設定と転送状態を確認しました。」の表示後、設定タブでnoteユーザー名または公開プロフィールURLを保存します。
8. `https://note.com/` やプロフィール左上のnoteロゴから専用ホームへ移動できます。

ZIPのリンクを押すだけではインストールされません。解凍と開発者モードでの読み込みが必要です。

「通常のnoteを表示（拡張OFF）」で通常ホームを開きます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。更新した場合は拡張管理画面とnoteタブの両方を再読み込みしてください。障害時は拡張を無効化してnoteを再読み込みできます。

非公式拡張です。note全体の通信を遮断するものではありません。Cookie・認証情報・記事本文を収集せず、ユーザー名・お気に入りタグと順序・ON/OFF・表示設定はブラウザ内に保存します。

0.2.0では3タブの専用ホーム、お気に入りタグの管理と新着順の記事検索、フォロー中のTLへの導線、note上の独自左メニュー、記事の固定TL・作者リンク、おすすめ欄の非表示設定を提供します。独自の記事収集・キャッシュ、AI、スキ等の自動操作はありません。

作者よりEdge・Chromeの動作確認済みとの報告があります。個別の通信・再起動・権限等の詳細確認は別途行ってください。

## ダッシュボードの無効化

専用ホームの「ダッシュボードを無効化する」にチェックし、「ユーザー設定を保存」を押します。ダッシュボード本体と全サブページへの移動を専用ホームへ戻し、note上のダッシュボードボタンを隠します。初期状態は未選択です。チェック解除後の保存、または全体OFFで通常どおり利用できます。ダッシュボードのボタン非表示・配下URLの転送・解除後の復帰は、利用者より実ブラウザで確認済みとの報告があります（2026-10-22、ブラウザ名は未記録）。

## 0.2.0の使い方

設定タブでユーザー名・ダッシュボード無効化・記事のおすすめ非表示・「0.1.1モード（重度引きこもりモード）」を保存します。タグは「お気に入りタグ」で追加・削除・並べ替えすると自動保存します。通常モードのタグ画面では左メニューから表示中のタグを追加できます。お気に入りは「#タグ名」の記事検索を新着順で開きます。重度モードでは設定タブだけになり、先頭のユーザー名のページへのリンクは使えます。タグと順序は削除しません。通常モードへ戻すにはモードのチェックを外して設定を保存します。

0.2.0は2026-10-25にリリース固定。利用者から動作確認報告がありますが、ブラウザ別・項目別の網羅確認結果は未記録です。詳細はリポジトリの `docs/manual-test.md` を参照してください。ここでのZIP導入は開発者向けの手動読み込みです。ストアの更新審査・公開は別途行います。
