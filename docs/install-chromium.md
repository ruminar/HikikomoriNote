# ひきこもりnote 0.3.7 — Edge / Chrome版の導入

0.3.6では、CtrlまたはShiftを押しながらお気に入りの追加ボタンをクリックすると先頭へ追加できます。左メニューではグループごとに一覧のスクロール位置を復元します。

0.3.3では記事のお気に入りと、8グループを使う「ひとみしりモード（2段）」を追加しました。従来のひとみしりモードは「ひとみしりモード（通常）」として4グループで使えます。2段版から通常版へ戻しても⑤〜⑧の内容は保持します。

設定画面の「設定の移行」でJSONを書き出し、別ブラウザ・端末へ読み込めます。8グループは形式9、4グループは記事なし形式7／記事あり形式8です。旧形式も読み込めます。8グループを別の製品へ移す場合は、移行先側にも8グループ対応が必要です。設定の移行前にJSONのバックアップを保存できます。

記事ページの「&」で登録先を選びます。専用ホームのお気に入りで削除・並べ替え・グループ移動ができます。通常版は①〜④、2段版は①〜⑧を選べます。

## 展開した拡張を読み込む

1. Chromium版ZIPをダウンロードして、任意のフォルダに解凍します。使用中はこのフォルダを移動・削除しないでください。
2. Edgeで `edge://extensions/`、Chromeで `chrome://extensions/` を開きます。
3. 「開発者モード」をONにします。
4. 「展開して読み込み」または「パッケージ化されていない拡張機能を読み込む」を押します。
5. 解凍したフォルダのうち、`manifest.json` が入っているフォルダを選びます。
6. ブラウザの拡張機能メニューから「ひきこもりnote」を押して専用ホームを開きます。
7. 「設定と転送状態を確認しました。」の表示後、設定画面でnoteユーザー名または公開プロフィールURLを保存します。
8. `https://note.com/` やプロフィール左上のnoteロゴから専用ホームへ移動できます。

ZIPのリンクを押すだけではインストールされません。解凍と開発者モードでの読み込みが必要です。

「通常のnoteを表示（拡張OFF）」で通常ホームを開きます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。更新した場合は拡張管理画面とnoteタブの両方を再読み込みしてください。障害時は拡張を無効化してnoteを再読み込みできます。

非公式拡張です。note全体の通信を遮断するものではありません。Cookie・認証情報・記事本文を収集せず、ユーザー名・お気に入りタグと順序・ON/OFF・表示設定はブラウザ内に保存します。

0.2.1では左メニューと右メイン領域の専用ホーム、お気に入りタグの管理と新着順の記事検索、フォロー中のTLへの導線、note上の独自左メニュー、記事の固定TL・作者リンク、おすすめ欄の非表示設定を提供します。独自の記事収集・キャッシュ、AI、スキ等の自動操作はありません。

作者よりEdge・Chromeの動作確認済みとの報告があります。個別の通信・再起動・権限等の詳細確認は別途行ってください。


## 設定と確認

動作モードはプルダウンから「ひとみしりモード（通常）」「ひとみしりモード（2段）」「社会復帰モード」「重度ひきこもりモード」を選び、「ユーザー設定を保存」で反映します。通常／2段の「お気に入り」で登録・削除・並べ替え・グループ移動ができます。

基本動作の確認にnoteアカウントは不要です。設定した公開プロフィールを開き、note上の「フォロー中のTL」を使います。公式ヘッダで未ログインと確認できる場合は空欄の新着検索へ進みます。ログインや購入などの公式操作にはnote側の通常の制限が適用されます。

## 設定の移行

専用ホームの「設定の移行」で設定JSONを書き出し、移行先で読み込みます。対応項目だけを取り込み、省略・不正項目は現在値を維持します。読み込み結果で適用項目・無視した項目と理由を確認できます。8グループの設定に旧4グループJSONを読む場合、記述のない⑤〜⑧は維持します。
