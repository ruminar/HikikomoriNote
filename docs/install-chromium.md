# ひきこもりnote v0.1.0 — Edge / Chrome版の導入

1. Chromium版ZIPをダウンロードして、任意のフォルダに解凍します。使用中はこのフォルダを移動・削除しないでください。
2. Edgeで `edge://extensions/`、Chromeで `chrome://extensions/` を開きます。
3. 「開発者モード」をONにします。
4. 「展開して読み込み」または「パッケージ化されていない拡張機能を読み込む」を押します。
5. 解凍したフォルダのうち、`manifest.json` が入っているフォルダを選びます。
6. ブラウザの拡張機能メニューから「ひきこもりnote」を押して専用ホームを開きます。
7. 「設定と転送状態を確認しました。」の表示後、noteユーザー名または公開プロフィールURLを保存します。
8. `https://note.com/` やプロフィール左上のnoteロゴから専用ホームへ移動できます。

ZIPのリンクを押すだけではインストールされません。解凍と開発者モードでの読み込みが必要です。

「通常のnoteを表示（OFF）」で通常ホームを開きます。再開は拡張アイコンを押すだけで、ONに戻して専用ホームを開きます。更新した場合は拡張管理画面とnoteタブの両方を再読み込みしてください。障害時は拡張を無効化してnoteを再読み込みできます。

非公式拡張です。note全体の通信を遮断するものではありません。Cookie・認証情報・記事本文を収集せず、ユーザー名とON/OFFはブラウザ内に保存します。

v0.1.0の機能は専用ホーム、設定、公開プロフィールへのリンク、通常表示切替です。記事一覧取得、タグ収集、AI、スキ操作はありません。

作者よりEdge・Chromeの動作確認済みとの報告があります。個別の通信・再起動・権限等の詳細確認は別途行ってください。
