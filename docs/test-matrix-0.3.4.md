# 0.3.4 確認項目

更新した開発版を再読み込みし、PC Chrome／FirefoxとAndroid Firefoxで確認する。結果欄は設けない。

| No. | 操作 | 確認内容 |
|---|---|---|
| 1 | Chromeの記事ページで&を開く | ライト／ダークでラベル・ボタン・状態文が読める。登録先を展開した選択肢も読める。広幅／ハンバーガー、通常／2段で確認。 |
| 2 | 有料記事非表示だけONでアカウントメニューを開く | ポイント残高・チャージ枠が消え、プレミアムと活用術は残る。 |
| 3 | おすすめ非表示だけON | プレミアムサービス・活用術と区切りの／が消え、ポイント枠とヘルプは残る。 |
| 4 | 両方ON／両方OFF・拡張OFF | 対象3枠の独立した切替と復元。メニューの開き直し・ページ移動後も同様。 |
| 5 | メニューの他機能 | 設定・自分の記事・履歴・参加中サービス・質問箱・ヘルプ・ログアウトの表示と操作を維持。 |
| 6 | [note活用術](https://note.com/help)・[安心創作勉強会](https://note.com/help/pg/event) | 通常版は4、2段版は8グループ。重度は自分のページだけ。社会復帰は公式左メニュー。本文とページ切替タブは維持。 |
| 7 | 活用術でグループ選択／幅変更 | グループ選択が保存され、狭幅では既存ハンバーガー。広幅への復帰・内部ページのSPA移動でも重複しない。 |
| 8 | 設定のお気に入り | タグ手入力欄がなく、note上の追加機能は維持。移動先は共通で初期未選択、自グループと非表示グループは選べない。 |
| 9 | 同じ移動先へ連続移動 | 全5種を移せる。移動先・一覧位置を保持し、移動先名を一覧近くに表示。保存中と成功時に全体の状態文を二重更新しない。 |
| 10 | グループ切替・モード切替 | グループごとの位置を保持。宛先が自グループや非表示グループになれば未選択に戻す。JSONには宛先・一覧位置を保存しない。 |
| 11 | 削除・上下／ドラッグ・失敗 | 操作後に同じ項目／隣の項目の操作へフォーカスが戻る。空なら一覧へ戻る。失敗時は元項目を保持し、成功扱いしない。 |
| 12 | 広幅／狭幅で長いタイトル | 操作列が揃い、狭幅ではリンクと操作部が上下になる。移動先は一覧スクロールの外にあり、320px相当でもはみ出さず操作できる。 |

自動テスト478件成功。メニューとお気に入り管理は合成DOMに基づくテスト。help系ページは公式DOMも読み取り確認済み。ログイン済みメニュー・PC／スマートフォン実機の表示と操作は未確認。
