## 通信の確認

1. 専用ホームでON・ルール適用済みを確認してから、プロフィールを開きます。
2. 開発者ツールのNetworkを開き、Preserve log（ログ保持）とDisable cacheをON、記録を消去します。
3. 左上のnoteロゴを押します。専用ホームへ直接移動し、通常ホームの文書の取得がないことを確認します。
4. アドレスバーから `https://note.com/` を入力し、通信前の内部転送で専用ホームになることを確認します。Networkに元URLの行が出ても、内部転送・ブロックの記録とサーバーから取得した応答を区別してください。応答ヘッダー・転送理由・接続先・Timingを確認します。
5. query付き、別タブ、再起動後についても同様に確認します。
6. OFFに切り替えると通常ホームの文書取得が再開することを確認します。

遮断の対象は `https://note.com/` そのものです。note側が別URLのAPIやService Workerで取得する情報、ルール適用前に発行済みの通信まで遮断するものではありません。ホームへの表示遷移を伴わない先読みも含め、実サイトでの通信状況はこの手順で確認が必要です。
