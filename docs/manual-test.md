## 手順と注意

1. READMEの手順で読み込み、ホームでユーザー名を保存してください。
2. 公開プロフィールへのリンクを開き、本人の公開記事へ到達できるか確認します。登録ユーザーが存在するかの自動検証は行いません。
3. OFFで通常ホームを表示し、投稿・下書き管理・ログインの公式導線が使えることを確認します。購入確認では決済を確定する必要はありません。
4. 記事を開き、ブラウザの戻る・進む、公式サイト内のホームへの移動を試します。ホーム外で拡張が残るならURLと操作を記録します。
5. 2つ目のホームタブを開き、片方で保存・OFF・ONを操作します。
6. 再読み込み、ブラウザ再起動、拡張の再読み込みをそれぞれ確認します。
7. 不具合が起きたら拡張を無効化してnoteを再読み込みすれば通常画面を利用できます。
